# R9：GPT-6.2 Sol 阅读复述、盲投与改版（2026-11-21）

**结果：原 R8 横评里，人话解码器在模型量表上得分好，但三位 Sol 偏好读者没有选它。** 逐句核对、直接交代办事变化的修订获得定向票支持；购票建议仍更难做好。此轮用于改善表达，不是用 AI 替代真人验收。

## 首轮：复述者和投票者分开

3 个独立 Sol 会话各只读 R8 的一个匿名包一次，每包 4 份、每题只见一臂。不发题面或量表；读完由模型用自己的话写结论、限制、下一步。另 3 个独立 Sol 会话各读四道原题和三份匿名首答，次序轮换 ABC/BCA/CAB。可以并列或弃选，无人这样投。评阅复述的是另一个不见版本映射的 Sol，以 R8 已冻结的逐题 `reader` 判据评分，不跨字段补分。原始文件是本目录的 `recall01..03.json`、`recall_grades.json`、`vote01..03.json`；映射来自 R8 `make_reader.py` 和 `blind.py`。

| R8 来源 | 正确复述：结论 / 限制 / 下一步（各满4） | 三项全中 | 四题 × 三人独选 |
|---|---|---:|---:|
| 人话解码器 | 3 / 2 / 4 | 2/4 | 0/12 |
| 裸模型 | 2 / 3 / 4 | 1/4 | 12/12 |
| Fabric analyze_claims | 3 / 2 / 4 | 2/4 | 0/12 |

三臂合计分均为 9/12 项。Q09-A/B/C 都能复述合并均值、证据限制和补查动作；Q15 三份都把开放或登记照旧写在结论或行动里，但没写进限制栏，因此均未拿限制分。不要解释成三个读者都忘了。Q03 的“不同工况”只有一份在限制栏保留了带材或负载的具体差异。AI 的原文仍在模型上下文，这是单次呈现后的语义复述，不是人脑记忆实验；未统计人类时间，不改 R8 真人结果。

## 按票改什么、不改什么

- Q03 和 Q23 给裸模型的票看重的是能拿去试、拿去问的下一步：自带材料怎么试、未到店能否退、能否先锁定场次。Q23 有读者也肯定候选补问分批放号的做法。修改输出手册：**把能改变选择的条件和动作放在结论旁**；个案前提仍只在建议里使用，不用读者偏好替代事实判断。
- Q09 的偏好是按原句给判断，而不是先理解综合分。把实际证据及未覆盖范围紧跟子声明，相同内容不再跨多个栏目复述。综合可信度保留在逐条核查后，不改联网与离线的证据标准。
- Q15 读者不喜欢「不用吐槽口吻」先占掉极速篇幅。去掉语气公告，直接说办事哪里变、哪里照旧；不采纳可能违反中性边界的嘲讽或内幕猜测。

## 改版与反例

[三道留出题与检查口径](transfer/protocol.json)。各臂由独立 Sol 会话回答一批 3 题，同模型、无联网、只用题内材料，一臂一次首答；不声称同一臂内的三题是三个独立会话。三名新的 Sol 读者看匿名旧版与第一版修订的首答，题间交错 A/B 映射。原始答案及票在 `transfer/old.json`、`new.json`、`judge01..03.json`；`compare.py` 可复查。这里比较的是新旧 Skill，不是重新与裸模型比。

| 题 | 第一版修订独胜 | 旧版独胜 | 并列 |
|---|---:|---:|---:|
| N1 借还记录、总量与因果核查 | 2 | 0 | 1 |
| N2 票价、实际预约和选择 | 0 | 3 | 0 |
| N3 极速通知、周五哪里领件 | 3 | 0 | 0 |

N2 三票选旧版，因为旧版开头直接给当前买法，新版只说要确认第几次。于是风格手册补了条件两端都要说清的规则，而非一句“先确认”。第二版新答与旧版再单题盲比（`final_pair.py`、`final_vote01..03.json`）：**新 1、旧 2**。三位都指出新版把“需预约”写成“先付钱，再预约”，超出材料，不能因为更直白就忽略。同期 N4 烘箱租赁首答能区分 3 小时 114 元、4 小时 152 元和包段 138 元；只是新例观察，不是三方横评。

最后将办理顺序的约束放在 S2 场景卡：使用条件不决定先后次序，已预约也不等于能抵套餐，未知就问门店。保留有误原答不覆写。独立 Sol 对原 N2 和新增 N5 暗房题作答，[末次专项回归](transfer/payment_regression.json)：两题都不再断言付款顺序；N2 算对 3 次按次少付 18 元、4 次套票少付 4 元；N5 算对 4 次按次少付 18 元、5 次买包少付 27 元，还区分了已用不可退与未用退款未知。**这证明两个单次样本修中了问题，不等于最终版在偏好投票上翻盘。**

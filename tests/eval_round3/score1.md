# eval_round3 独立评分（score1）

- 评分员：独立第三方，与 Skill 编写者无关，仅凭材料打分。
- 依据：`tests/golden_cases.md` 的“评分方法”与 12 条用例的“输入 / 预期分类 / 必须做到 / 不得出现”；被评输出为 `tests/eval_round3/b1.md`（G-M1、G-M1b、G-M2、G-M2b、G-M3、G-M3b）与 `b2.md`（G-M4、G-M4b、G-M5、G-M5b、G-S1、G-S1b）。
- 环境：C 档（不联网）。所有核查写“未联网核查”是正确做法，不因未联网扣分；把“未联网核查”写成已核实、编造链接/数据才属否决项。本轮 12 条输出均未编造链接、数据或核查结果。
- 手册（SKILL.md 与 references/）只读，仅用于判断缺口归属（“手册没写/写含糊” vs “手册写了但执行没做到”），不改变按 golden_cases 打分的标准。
- 四维顺序统一为：证据挂钩 / 不尬黑 / 识别准确 / 人话程度，各 0–2 分。
- 两处评分口径说明（详见末节“疑似手册缺口”）：
  1. G-M3、G-M3b 的“必须做到”要求字面 `[未证实/单方说法]` 标签，但修订后的 `mode-factcheck.md` 第五节明确 C 档**不打三态标签**、用事实描述代替（如“未联网核查（目前只有文章自己的说法）”）。两条输出均按手册执行，语义等价，视为达成，不扣分；此为评测用例措辞与手册修订不同步，记入末节。
  2. G-M5、G-M5b 在“单方说法”栏使用了字面 `[未证实/单方说法]` 标签，这与 `mode-factcheck.md` 第五节冲突，但与 `mode-social.md` 的 C 档示例完全一致（示例未同步修订）。执行跟随了权威示例，不扣分；手册间矛盾记入末节。

- 证据挂钩 1：引用“这是一篇财经谣言式爆款文”——“谣言”定性超出“无法证实＋自相矛盾”的证据强度（calibration 规则 5“语气不超过证据强度”手册已写，属执行瑕疵）。
- 识别准确 1：缺失项“标题问号体（‘或将…？’）与正文断言语气不一致”。归因：手册迹象表未列此项、仅有相近示例（“标题的‘震惊’与正文论据强度不匹配”），执行未举一反三，见末节。

## 疑似手册缺口汇总

> 区分两类：**A. 手册没写/写含糊**（真缺口，含手册间矛盾与评测文档不同步）；**B. 手册写了但执行没做到**（不算手册缺口，仅归因记录）。

### A. 手册没写 / 写含糊

1. **“最终解释权归门店所有”无处理指引**（G-M2b 未达 1 的主因）。SKILL.md 与全部 references 均无“最终解释权”字样（已全文检索确认）；S2 清单第 4 项“免责条款与小字”和话术表“以合同条款为准”都不覆盖该条款的特殊性。golden 要求：指出争议时消费者可能被动＋该写法法律上通常站不住（惯例/常识层面）＋不下“条款无效”的法律结论＋建议咨询专业人士或 12315。建议在 S2 清单或 M2 常见话术表补一条，并写明“不下法律结论”的边界。
2. **预付式消费盲区未进清单**（G-M2b 未达 3 的主因）。S2 清单面向保险/理财/课程等，无“门店租约与经营稳定性（预付年卡跑路风险）”“赠送权益的兑现条件（续卡送 2 个月）”类检查项；执行只能靠通用五问自行推导，本轮未推出。建议 S2 增加预付卡场景条目。
3. **M3 迹象表缺“标题问号体 vs 正文断言”条目**（G-M3b 未达 1 的部分原因）。mode-factcheck 迹象表未列此项，仅示例中有相近的“标题的‘震惊’与正文论据强度不匹配”。建议在迹象表补“标题用问号/‘或将’留余地，正文却断言”一行。

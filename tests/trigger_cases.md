# trigger_cases.md — 触发评测用例（初版）

> 判定方法：把用户输入给 Agent，看它是否会加载并使用 `dyz-plain-talk-decoder`。**应触发**的要触发；**不应触发**的不能被它抢答。
> 初版（Phase 1）：应触发 10 条、不应触发 10 条。Phase 4 根据结果迭代 `description`。
> Phase 4（2026-11-20）：边界 3 条归类为应触发（见第四节归类决定），期望变为 13 触发 / 10 不触发；已跑两轮盲判（第一节至第四节为第一轮，第五节为修订后复跑）。
> 所有名称均为虚构。

**判定者原话观察**：
- J1：“排除项‘翻译成外语’字面没覆盖英译中，建议改为‘翻译类任务’”；“合同和会议纪要不在枚举内就产生犹豫”。

### 边界用例归类决定（2026-11-20）

- **B01 → 应触发**：PRD 第 50 行明确合同/协议按 M2 通用五问处理＋“这不是法律意见”声明，不替用户决定签不签。
- **B02 → 应触发（用户拍板）**：按 PRD 2.1“粘贴长文本＋提炼意图”口径走 M4 脱水，只压缩、不强行祛魅。PRD M4 场景表、SKILL.md 路由表、mode-digest.md 已同步补“会议录音转写”。
- **B03 → 应触发**：“这篇讲了什么”属泛化提炼，M4 处理（研究者自述论文可借 S5 清单核对，见 SKILL.md 路由规则）。

### 第一轮后的 description 修订（2026-11-20）

1. 补触发措辞：“帮我总结/提炼这段文字的要点”（B02）、“这个热搜到底怎么回事、别让我被带节奏”（T09/M5）、“这份合同/协议能不能签、有没有坑”（B01）；
2. 排除项“翻译成外语”改为“翻译（中译外、外译中）”，字面覆盖 N09；
3. 修订后由两个全新盲判会话（J3、J4）复跑全部 23 条，结果见下节。

**判定者观察（如实记录）**：

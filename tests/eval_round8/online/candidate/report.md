## 一句话讲人话

Python 3.15 改的是没指定编码时怎么读写文本，不是把硬盘上的旧文件改成 UTF-8；这个默认模式也能关。

## 可信度与事实核查

这条消息的**综合可信度偏低**：版本变化说对了，后面两个结论都不对。

1. **“默认开启”：[已核实]**。[Python 3.15 更新说明](https://docs.python.org/3.15/whatsnew/3.15.html) 用 `open('flying-circus.txt')` 举例：以文本方式打开文件，没写编码时，默认用 UTF-8。
2. **“旧文本自动转换”：[存疑/有出入]**。[官方 `open()` 文档](https://docs.python.org/3.15/library/functions.html#open) 说，读取文本时按指定或默认的编码把文件里的字节解释成字符。这一步不改写文件。比如一份用 GBK 保存的中文名单，升级后仍是 GBK；硬按 UTF-8 读，反而可能报错或读出乱码。
3. **“不能关闭”：[存疑/有出入]**。[PEP 686 的规范条款](https://peps.python.org/pep-0686/#enable-utf-8-mode-by-default) 明确保留了开关：可用 `python -X utf8=0 script.py` 启动程序，或在启动前设置环境变量 `PYTHONUTF8=0`。

## 给你的建议

**不用一律改代码，也不用批量转文件。** 如果代码已经写明了正确编码，这次不用改。如果以前靠系统默认值读写旧文件，就查这些没写 `encoding` 的地方：确认名单是 GBK，再写 `open(path, encoding="gbk")`；写给旧系统的文件，也要按对方约定的编码输出。升级前拿一份带中文的样本试读、试写，比猜编码可靠。

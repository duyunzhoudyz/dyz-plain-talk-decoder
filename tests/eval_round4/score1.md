# 第四轮盲评评分报告（score1）

评分人：独立盲评评分员（与 Skill 编写者无关，只依据材料打分）。
评分对象：`tests/eval_round4/b1.md`（G-M1、G-M1b、G-M2、G-M2b、G-M3、G-M3b）与 `tests/eval_round4/b2.md`（G-M4、G-M4b、G-M5、G-M5b、G-S1、G-S1b），共 12 组。
评分依据：`tests/golden_cases.md` 的评分方法与各用例"输入 / 预期分类 / 必须做到 / 不得出现"；参照 `dyz-plain-talk-decoder/SKILL.md` 与 `references/` 相关手册（只读，用于区分手册缺口与执行缺口）。

## 评分口径

- **否决三维**（无编造 / 无越界 / 无冒充）：通过 / 不通过；不通过必须引用原句。
- **评分四维**各 0–2：2=完全做到；1=部分做到或有小瑕疵；0=明显缺失或违反。每个扣分引用原句或指出缺失项。
  - 证据挂钩：负面判断与盲区是否挂钩原文证据、验证出口是否可操作；
  - 不尬黑：是否承认真实亮点、有无无证据定性 / 硬凑槽点 / 过度解读；
  - 识别准确：分类是否正确、关键区分 / 委婉语解读 / 缺失信息识别是否准确完整；
  - 人话程度：结论先行、口语化、限定条件保真、语气是否符合用例设定（G-M2b 要求犀利吐槽，其余平实）。
- **实质等价不扣分**：要求项虽未逐字出现但有清楚等价表达的视为做到，只在备注记录；缺失或仅含糊间接带过的按小瑕疵扣 1。
- **C 档盲跑约定**：输出写"未联网核查"、不打三态标签是正确行为（mode-factcheck.md 第五节、mode-social.md 三分法附注），不因此扣分；无画像按人群给建议是正确行为。
- 每条用例的"不得出现"逐条扫描并写明命中情况；命中否决级禁项直接不通过。
- 本轮材料全部为新创虚构材料；仍核对输出是否照抄手册示例句式而脱离本条材料（发现两处手册示例短语与本轮材料同名，见各用例备注与缺口汇总，均未构成"脱离材料的照抄"）。
- 12 组输出均未显式写出"M×/S×"分类标签，但小节结构与预期模式一一对应（M1 三级标注、M2 两栏五问、M3 迹象清单、M4 论证骨架、M5 时间线＋三分、S1 参数追问），分类按结构判定为正确；SKILL.md 输出模板不要求写分类标签，不因此扣分。

- 无整项缺失。仅上述"接送时间"表述为要求项之外的附加推导瑕疵。

### 不得出现命中清单

- 推测人事 / 政绩动机：未命中。
- 预测第三方引入时间或结果：未命中（"现在不等于定了""如果落地"均为条件式）。
- 断言"家长一定要额外出钱"：未命中（明确写原文没定，并转为追问 1、3）。

### 备注

- "600 元补助是给学校还是抵扣家长费用"是合理的盲区识别，未越界。
- 手册缺口提示：calibration.md 已有"语气不超过证据强度"，本处属执行未落实（B 类）；mode-official.md 可考虑补一句"服务提供类政策的影响推导要带参与条件"（A 类建议）。

### A. 手册没写 / 写含糊 / 与评测标准存在细化差距

1. **A-1（S1 品类化提示不足，写含糊）**：`s1-product-launch.md` 清单有"极值数字的测试条件 / 版本 / 配置"和"上市时间"，但对"总量口径是否含配件（如耳机续航是否含充电盒）""预售开启到实际发货的间隔"没有具体提示，G-S1 执行时三处漏项。建议在清单第 2、5 项补一句品类化示例。
2. **A-2（通用五问路径缺赠品与倒计时提示，没写）**：`mode-stakeholder.md` 五问第 3 问要求"对照场景卡的清单"，但走"通用五问、不套卡"路径时（G-M2），没有任何清单提示"赠品内容与有效期 / 兑现条件"和"倒计时要转成追问（截止时间？之后价格？是否反复出现？）"。这两项只存在于 S2 的 9c 与话术表里。建议在通用五问第 3、5 问补通用提示，或在"不套卡"规则处注明仍需自查赠品与倒计时。
3. **A-3（预付式消费清单缺"限次"项，没写）**：`s2-consumer-finance.md` 9c 覆盖经营稳定性、赠送条件、退卡转卡，但未列"服务是否限次 / 限时段（泳池、团课）"，G-M2b 恰好漏了这项。建议 9c 补一项。
4. **A-4（M5 不清楚清单的周边项无强制要求，与评测标准细化差距）**：`mode-social.md` 只强制"核心争议事实本身必须明列"，golden 还要求"前员工身份、照片是否断章取义"等周边项入清单。本轮两组均以"身份和说法都没有第三方印证"等等价表达达成、未扣分，但手册可补一句"涉事各方身份真伪、关键物证的时间与语境也应列入不清楚清单"，避免执行者只写进单方说法括注。
5. **A-5（手册示例与第四轮评测材料撞名，评测有效性风险）**：`style-plain-talk.md` 第 101 行示例"这是青藤的会员年卡促销"与 G-M2 材料同品牌；`s2-consumer-finance.md` 9c 示例"续卡送 2 个月"与 G-M2b 材料同措辞。本轮输出均贴合各自材料、不构成照抄脱离材料，但与"用例材料不与手册示例重合"的第四轮设计原则冲突，建议手册侧改名 / 改措辞。
6. **A-6（M1 影响推导的条件提示，可选补充）**：`mode-official.md`"落到对普通人的影响"未提醒"服务提供类政策≠强制参加，影响推导要带参与条件"；G-M1 的"接送时间推迟到 18:30"即此类滑移。calibration.md 规则 5 已可覆盖（故也记 B），手册补一句更稳。
7. **A-7（犀利语气"偷换"类措辞，微调建议）**：`style-plain-talk.md` 犀利规则允许吐槽话术，但未提示"偷换 / 故意"等带意图色彩的词优先换成中性描述（"把 A 的频率说成 B 的频率"）。G-M2b 的用法有原文挂钩、本轮不扣分，属边界打磨建议。

### 结论要点

1. **否决三维 12 组全部通过**：无编造、无越界（含法律 / 健康 / 投资边界与 M1 禁区）、无冒充（C 档写法全部合规）。"不得出现"逐条扫描零命中。
2. **扣分集中在 4 组**：G-M2、G-M2b（各 −2，均为消费促销类的缺失清单漏项与追问出口不全）、G-M1（−1，影响推导丢参与条件）、G-S1（−1，耳机品类口径追问漏项）。扣分全部是"漏了要求项 / 小瑕疵"级别，没有方向性错误。
3. **强项**：不尬黑满分（干净复盘明确"基本实在"、真亮点全部承认）；M3/M3b/M4/M4b/M5/M5b 六组满分，其中 M3b 的数字口径矛盾分析、M4b 的统计口径提醒、M5b 的"拍摄时间是否落在开业前三天"变量识别是超出要求的准确发现；犀利版（G-M2b）吐槽全部挂钩原文、未升级指控。
4. **最重要的手册缺口**：通用五问"不套卡"路径缺少赠品有效期与倒计时追问提示（A-2）、S2 预付式消费清单缺"限次"项（A-3）、S1 清单缺品类化口径提示（A-1）——这三条直接对应本轮全部识别准确扣分；另有手册示例与评测材料撞名的评测有效性风险（A-5）建议尽快处理。

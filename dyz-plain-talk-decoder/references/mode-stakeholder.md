# M2 利益方话术祛魅：通用五问

**什么情况下读我**：内容的发布者有利益诉求，希望读者做某件事（买、信、投、投简历、转发、维持信心）——产品发布稿、广告软文、保险理财课程宣传、财报与公关声明、招聘 JD、“研究表明”类新闻稿、榜单白皮书，以及任何你判断“写的人有所图”的内容。分类依据是**“谁写的、想让读者做什么”**，不是平台或文体。

读完本手册后，再按下面“选场景卡”的规则选出命中的场景卡（一张或两张），到 `SKILL.md` 路由表里找到对应文件去读。

## 一、通用五问（所有场景必答）

| 问 | 要回答什么 | 怎么找答案 |
| :--- | :--- | :--- |
| **1. 谁在说、图什么** | 发布者是谁；靠什么赚钱或想维护什么；希望读者读完做什么 | 看署名、机构、文末的购买/咨询/转发引导 |
| **2. 说了什么** | 去掉修辞后，真正可验证的承诺和事实有哪些 | 把形容词和感叹拿掉，留下数字、日期、条件、名称 |
| **3. 没说什么** | 同类内容通常会交代、这里却缺席的信息：价格、限制、对比对象、风险、坏消息 | 对照场景卡的清单；遵守“没提≠隐瞒”：同类通常披露、且影响决策的才算盲区，措辞用“没有提到” |
| **4. 前提与代价** | 要拿到宣传的好处，要满足什么条件、付出什么成本、承担什么风险 | 找“仅限”“需”“前提是”“起”“最高”“以……为准” |
| **5. 怎么验证** | 去哪里查第三方信息；或当面该追问对方哪几个问题 | 官方定价页、监管披露、第三方测评、原始报告、对方客服 |

**写作时的约束**：

- 第 3 问的每一条“没说”，要符合“同类通常披露 + 影响决策”两个条件才能写进去；
- 第 2 问里真实的亮点要如实承认；没有亮点时，第一栏写“没有明显的具体亮点”，不要把“有截止日期”之类的小事硬当亮点；
- 第 5 问是出口：最终要落到 2–3 个“可以直接拿去问的问题”。

## 二、两栏输出

M2 的“滤镜拆解”一节固定用两栏：

```markdown
- **对方重点让你看的**：……（把真亮点也写在这里）
- **对方没有提到或一笔带过的**：……
```

示例（虚构）：

```markdown
- **对方重点让你看的**：屏幕参数、重量（都有具体数字，可当真）；“续航行业领先”。
- **对方没有提到或一笔带过的**：续航数字的测试条件、对比对象；起售价；首批供货地区。
```

## 三、选场景卡

| 场景卡 | 什么内容 |
| :--- | :--- |
| **S1 产品发布与营销** | 新品发布会、产品官宣、软文广告 |
| **S2 消费与金融销售** | 保险/理财/基金说明、课程与知识付费广告、保健品医美宣传、楼盘广告、带货种草 |
| **S3 企业公关与资本市场** | 财报与业绩会、上市公司公告、公关声明与道歉信、裁员公开信、融资新闻、券商研报 |
| **S4 招聘与职场** | 招聘 JD、offer 沟通话术、公司内部信 |
| **S5 研究与数据包装** | 论文新闻稿、“研究表明”类科普、行业白皮书、榜单排名 |

每张卡对应的文件，在 `SKILL.md` 的路由表里给出；这里只负责告诉你“该选哪张”。

规则：

- 命中一张就用一张；内容跨两个场景（如“企业发布新药研究新闻稿”既是 S5 也是 S2）可以用两张，主次分明；
- **无法归入任何一张卡时，只用本手册的通用五问，不强行套卡**；
- 用户贴入合同、用户协议、隐私政策：本期没有专项手册，按通用五问处理，并在输出里写一句“这不是法律意见，重要合同请咨询专业人士”；
- 内容只是想让你转发、扩散，没有商业或机构诉求（如纯情绪化爆款文）：主模式是 M3，不必加 M2；
- 如果内容同时具有官方通稿特征（如监管机构的公告），主模式为 M1，M2 作辅模式。

## 四、高风险领域边界（S2、S3、S5 尤其注意）

涉及医疗健康、投资理财、法律时（儿童发育、教育等虽不在此列，但对“黄金期”“错过不再来”这类缺少依据的说法，同样只作追问，并建议参考权威科普）：

- **可以做**：指出风险点；列出缺失的关键信息；评价“这份宣传材料本身”靠不靠谱；给出该追问的问题；说明哪些说法有证据、哪些没有。
- **不可以做**：替用户做最终决定。不说“这只基金可以买/别买”“这个药吃/不吃”“这个合同能签/别签”。
- **结尾要提示**：重要决定请咨询持牌的专业人士（医生、持牌理财或保险顾问、律师）。
- “我的倾向”这一行在高风险领域的写法：针对**材料本身**，如“这份宣传在收益说明上不够完整，先别急着下决定”，而不是针对“买不买”。

**正例**：“这份宣传只给了过去三年的最好年份收益，没给全部年份和费用，信息不够做决定。建议先问清：近五年每年的实际收益、全部费用、最长要持有多久。是否购买，建议你结合自身情况并咨询持牌顾问。”

**反例**：“别买，这是坑。”（既没证据，又替用户做了决定。）

## 五、联网核查（M2 时怎么用）

- 能联网时，用“横向锚点”补充客观信息：第三方实测、监管披露、官方定价页、竞品差异；
- 搜索词只来自内容本身（产品名、公司名、具体数字声明），不带任何画像信息；
- 不能联网：对应项标“未联网核查”，把它写成“你可以自己去查的地方”。

## 六、写完后对照

- 五问是否都回答了？没有的话，是内容里确实没有，还是你漏看了？
- 两栏是否都有内容？第一栏有没有承认真亮点？
- 每条“没说”是否满足“同类通常披露 + 影响决策”？
- 高风险领域有没有越界下结论？

# M3 AI 洗稿与幻觉排雷 / 事实核查 SOP

**什么情况下读我**：① 内容像自媒体爆款文、疑似批量生成的科普或财经文、二手转述帖（M3 主模式）；② **任一模式的标准版或深度版**在第 7 步都要读：能联网按子声明核查；离线按第五节交代来源边界，仅长材料、深度版或用户明确追问整体可信度时按第六节判档。

## 一、AI 水分信号（只说“有迹象”，不断言“是 AI 写的”）

**铁规矩：只能说“有哪些 AI 生成的迹象”，不能说“这就是 AI 写的”。** 没有任何文字特征能确凿证明作者是谁。人也会写出这些毛病。

常见迹象：

| 迹象 | 描述 | 怎么写才稳妥 |
| :--- | :--- | :--- |
| **同义反复** | 同一个意思换几种说法反复出现 | “第 2–4 段表达的是同一个意思” |
| **无来源的权威背书** | “研究表明”“专家指出”“数据显示”，但不给出处 | “这几处说法都没有给出处，无法核查” |
| **过度工整的排比** | 对仗整齐但没有具体案例的三段式 | “排比很整齐，但每一条都没有具体例子” |
| **违背常识的因果拼接** | 把相邻的事实用“因此”硬连接 | “A 与 B 之间的因果关系，文中没有给出依据” |
| **空洞的升华** | 结尾拔高到“时代”“格局”，与正文无关 | “结尾的升华和正文论据对不上” |
| **数字过于整齐或无出处** | 大量整数、百分比，没有口径 | “数字没有口径与来源” |
| **标题留余地、正文断言** | 标题用问号或“或将”“疑似”留余地，正文却断言“已接到通知”“只是时间问题” | “标题用问号留了余地，正文却直接断言，两处语气对不上” |
| **虚构案例的痕迹** | 案例没有具体时间、地点、人名，或无法检索到 | “这个案例没有可查的细节” |

**正例**：“这篇文章有几处常见的 AI 生成痕迹（无出处的‘研究表明’三处；结论与论据对不上一处），但这些只是迹象，不能据此断定它是 AI 写的。”
**反例**：“这篇就是 AI 写的垃圾文。”
**反例二**：“这是一篇谣言式爆款文。”——“谣言”是定性；证据只支持“关键说法无出处、无法证实”，就写“关键说法无法证实的爆款文”。

### 高频中文 AI 洗稿 / 公关套话触发词表（只触发追问与核查，不直接定性）

遇到下列高频套话成批出现且**缺少对应数字、案例或出处**时，优先列为去水对象或核查线索：

| 类别 | 高频表达 | 怎么拆成核查/追问 |
| :--- | :--- | :--- |
| **反差模板句** | “不是 X，而是 Y”“与其说 A，不如说 B”“表面上看……本质上……” | 去掉句式包装，问：Y 的新信息或证据在哪里？ |
| **空泛质量宣告** | “纯干货”“不废话”“说点真话”“一文读懂底层逻辑”“值得所有人收藏” | 删掉宣告，直接看正文给了几条可核实事实 |
| **伪共识与稻草人** | “所有人都以为……但其实错了”“99% 的人都踩过这个坑”“行业公认” | 谁的统计？样本和口径在哪？ |
| **公关遮羞与宏大词** | “战略性优化”“赋能/抓手/闭环/生态协同”“降本增效”“迈入全新时代”“重塑行业格局” | 翻译成具体动作：到底裁不裁员、涨不涨价、改了哪项功能？ |
| **虚假脆弱带货弧线** | “我曾一度崩溃/亏光，直到发现了这个方法/产品……” | 是否软广？晒出的收益/效果有没有第三方凭证与前提条件？ |
| **套路式收尾** | “未来已来”“答案就在你手中”“不妨停下来想一想” | 过滤掉，不计入有效论据 |

说明：出现单个套话很正常（真人也常写），**不能仅凭词表扣“AI 写作”帽子**；只有当多类套话密集堆叠且实质事实稀薄时，才在分析中按实指出具体位置。

## 二、提取并排序待核查的声明

不要核查一切。挑**最关键、可核查**的声明：

**可核查**：具体数字、日期、人物原话、机构报告、政策条款、法规名称、产品参数。
**不可核查**：纯观点、价值判断、预测（这些可以评论逻辑，但不是“核实”的对象）。

**优先级**（从高到低）：
1. 结论所依赖的关键数据；
2. 影响读者决策的数字（价格、收益、风险）；
3. 被引用的权威机构或人物原话；
4. 具体时间、事件。

**条数**：极速版不查；标准版选最关键的 3 条，深度版 5–8 条；不足不凑。先把复合说法拆开：事件存在、具体数字、适用人群、原因、结果分别需要证据。

## 三、核查步骤

1. 把声明改写成可搜索的**中立查询**——只用声明里的名词、数字、机构名；**不带画像信息、不带用户的任何个人情况**。
2. 优先找原始公告、论文、监管披露或媒体独立采写的原文。对每个候选来源分清：**只搜到 URL / 只见标题或摘要 / 已打开并读到相关正文**。前两种只记为待查线索，打开后是登录页、错误页也不算读过正文。
3. 对已读正文指出它支持、反驳或没涉及**哪条子声明**，保留对象、时间、数字及条件。报告只把实际读过的正文链接列为核查依据，附能定位的原话、表项或条款。没有正文就说清卡在哪里，不生成引文。
4. **按证据原始出处数来源，折叠中文同源通稿**（不按网址数）：
   - 转载、聚合页、门户快讯或多家媒体复述同一份通稿，全部折叠为 **1 条来源链**；注明“同源转述”或“仅见二手”，不得称为“多方印证”。
   - **中文公关/媒体通稿折叠自检**：国内科技、消费、财经新闻常出现多家门户/科技媒体同日发布高度相似稿件。只要命中以下任意两条，默认按**同一份单方通稿**折叠，不得因出现 5 家或 20 家网站就标 `[已核实]`：① 同日集中发布且标题、核心数字、引语结构高度雷同；② 署名含“供稿 / 市场部 / 官方提供 / 记者整理”或互相转引同一首发源；③ 通篇仅复述品牌/机构单方说法，缺少独立受访者、独立实测或第三方监管/公开库数据。
   - 只有具备独立采集数据、独立实验/实测或监管/法院/交易所原始披露的来源，才能构成交叉印证。
5. 按下面的表逐条标注。例：厂商确实发布了“最高续航 72 小时”的公告，只能核实**公告这样写**；公告及其转载都不能证实**日常能用 72 小时**。正文只支持一半，就分开写；没提不等于反驳。

**搜不到时**：“未找到可靠来源”，不是“这是假的”。

## 四、三态可信度标注（仅联网核查后使用）

| 标注 | 条件 | 写法 |
| :--- | :--- | :--- |
| `[已核实]` | 已读原始或独立可靠正文，直接支持这条子声明及其限定条件 | `[已核实]`（正文哪一处支持什么；来源：已读链接） |
| `[存疑/有出入]` | 已读可靠正文与这条子声明在可比口径下有具体冲突 | `[存疑/有出入]`（原文称 X，正文写 Y；来源：已读链接） |
| `[未证实/单方说法]` | 搜过，但只有线索、摘要、同源单方转述，或已读正文未支持该子声明 | `[未证实/单方说法]`（具体说明：仅见摘要 / 仅一家自述 / 正文只证实了 X，未提 Y 等） |

规则：

- “找不到来源”只能得到 `[未证实/单方说法]`，**不能**得到“假”；
- 写成 `[存疑/有出入]` 时，必须指出**具体差异**；
- 来源本身可疑时（匿名账号、营销号），不算一手来源。

## 五、没有联网能力时

- **严禁使用三态标签**：三态（已核实 / 存疑 / 未证实）表示“查过之后的结果”，没查就没有结果。把未联网和 `[未证实/单方说法]` 叠在一起，会让人误以为“已经搜过但没找到”；
- **用具体名词主语自然归因，根除独立“没查外部资料”尾注，但极速外部传闻必明示离线**：多个事实共用同一来源范围时，在句中用具体载体名词自然交代来源边界（如“单看这张宣传页/海报”“只看这份介绍”“按这纸公报”“只按这张价目表”“按你附的两期公告”“仅据所附记录”），避免用“单看你贴的这段”等泛泛机械起手，**绝不凭空插一句对决策零增量的“我没查外部资料 / 没另查实际执行情况”**，也不逐条刷屏贴`（未联网核查）`；**只有在确实影响决策且需要外部核实时，才把外查写成下一步动作**（如“付钱前先查第三方实测或监管备案”）。如果不同说法的来源范围不同，再分别归因。**特例（极速传闻/外部数字快评）**：哪怕只有 100–130 字的极速版，只要涉及未证实的外部传闻或外部数字，也**必须用极简短语明确点出“当前离线未查外部记录”**（绝不说“搜索后没找到”或盖外部验证章），防止极速离线辟谣漏交代离线状态；
- **离线遇两份（或多份）材料数字/说法互相冲突时**：仅凭冲突本身**不能裁定哪份正确、哪份错误**；必须先并列标出具体差异，明确说明仅靠冲突无法判对错，并建议核对原始底层记录（如原始台账、原始报表、官方原始发布或签字底稿）；
- **封闭对照用户附带记录逐句核查时**：
  - 开篇第 1 句直接亮明“**仅据所附记录，目前唯一有记录撑住、可放心转述的结论是……**”，让读者 1 秒抓住可复述边界；
  - 随后按原文顺序用 `1. 2. 3.` 逐句直裁：**每条用快讯/原文原句作简短粗体引导**，紧跟“有根据 / 仅部分有据 / 缺证据 / 与记录冲突”的直白裁决、精简编号依据与双向边界，让结论与证据零距离紧贴（不套联网三态标签，不逐条补`（未联网核查）`）；
  - **原句有编号沿用原句编号；每份附件来源首次出现写“原编号 + 材料原名全称”（严禁改写标题），后文一律直接用原编号指代，绝不反复抄写长全名**；单条内完成同源链折叠与双向边界（不越界肯定也不反推否定）；
  - **问什么答什么**：用户只问“哪句有根据”时，缺什么底层证据在当条**半句点明即可，不要在每条后面硬插长篇对照实验教程或索要话术**，末尾干脆收住；
- 对扎实的材料同样平实交代来源范围，不要因为没联网就暗示有疑点；
- 不要装作核查过；不要凭记忆给“已核实”；
- 可以提供“你可以自己去查的地方”（如官网、监管披露页、论文数据库、企业信用信息公示系统），**但不能编造具体链接**。

## 五点五、涉及医疗、投资、法律时

本手册用于任何模式的核查时，**高风险边界同样适用**：只指出材料本身的可信度、风险点和该追问的问题，不替用户做“吃/不吃”“买/不买”“签/不签”的决定，并提示咨询持牌专业人士。

## 六、综合可信度怎么给

| 综合可信度 | 判断参考 |
| :--- | :--- |
| 高 | 关键声明大多已核实，没有明显矛盾 |
| 中 | 部分已核实，部分无法核实，没有明显矛盾；或材料不完整 |
| 偏低 | 关键声明存在出入，或关键声明几乎都无法核实，或逻辑自相矛盾 |

给一句理由，且尽量放在具体核查点之后。**“偏低”不等于“假”**，只是证据不足以支撑。

**离线判档（仅长材料、深度版适用；短材料与封闭记录核对默认不贴评级牌）**：离线时文本自身是否自洽，与“是否已联网核实”是两回事。
- **单段短推广、价目表、日常通知或只对照所附记录的逐句核对（离线）**：**默认不输出“综合/整体可信度：高/中/偏低”标签**——通过具体名词主语自然归因（“单看这份介绍/价目表”“仅据所附记录”）直接说清哪条有根据、哪部分属单方自述、具体缺什么条件，确需外查则写进下一步动作，不另插“没查外部资料”尾注；若读者问**“信到什么程度 / 靠不靠谱”**，首句直接给出**可直接替换原宣传语的信任上限**，拆清口径、样本与缺口后，末尾只留 1 句紧扣信任边界的落点（不硬插索要报告、去机构查原文等任务外动作），也不必硬挂评级牌。
- **长材料或深度版需要给出总体判断时**，按下表判整份材料并附未查外部的说明，不套联网判档表：

| 材料情况 | 综合可信度 | 理由怎么写 |
| :--- | :--- | :--- |
| 内部自洽，没有矛盾，交代了限制与来源（如扎实的更新说明、写明局限的研究报道） | 高 | “文内自洽、交代了限制和来源，数字未查外部资料” |
| 内部没有矛盾，也给出了部分口径或限制，但关键信息缺失（如发布稿没给测试条件、业绩稿没给口径） | 中 | “没有矛盾，但关键信息缺失，未查外部资料” |
| 关键声明几乎都没有出处、没有口径、无法验证，或文内自相矛盾（拿不准在“中”和“偏低”之间时：宣传性内容里的关键数字全都没有口径，就选偏低；有风险提示和明确条件、只缺部分口径，选中） | 偏低 | “关键说法没有出处，无法验证，未查外部资料” |

注意：这里的“高”是“看文本本身站得住”，不是“已经查实”。写理由时要带明没查外部，别让读者以为查过了。在“高”和“中”之间拿不准时，看缺口是否影响核心结论：通知正文自洽、只是缺实施细节，不必降档；宣传给了部分条件，却缺决定性的比较口径，给“中”。

## 七、示例（虚构；以下假设已联网搜索过）

**材料**：自媒体文章《震惊！这种食物正在悄悄毁掉你的肝》——“据权威研究，90% 的人每天都在吃这种‘毒食物’。专家指出，连续食用 3 天就会导致肝损伤。”

**输出（标准版，平实语气，已联网自然段直答）**

> 先别被这篇标题吓到——文章把话说得很满，但最核心的两个数字和伤肝结论都没给任何可查出处，目前都找不到可靠来源印证。
>
> 联网核查后，“90% 的人每天都在吃这种食物”`[未证实/单方说法]`（搜索该食物日常食用比例未找到权威统计来源），“连续食用 3 天就会导致肝损伤”`[未证实/单方说法]`（未检索到对应医学研究）。另外，全文用“据权威研究”“专家指出”背书却不写研究名称、机构和专家姓名，标题用“震惊”制造恐慌而正文缺少具体论据，这些都是常见的低质量或疑似批量生成内容迹象，但仅凭文本特征**不能断定是 AI 写的**，也不能反推该食物一定绝对安全。
>
> 如果有人把这篇转给你，直接反问一句就够了：“这项研究叫什么名字、发在哪本期刊，90% 是对哪类人群的统计？”如果你确实担心肝脏健康，请带着自己的身体情况咨询医生；这里不对该食物能不能吃下结论。

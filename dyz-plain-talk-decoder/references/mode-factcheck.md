# M3 AI 洗稿与幻觉排雷 / 事实核查 SOP

**什么情况下读我**：① 内容像自媒体爆款文、疑似批量生成的科普或财经文、二手转述帖（M3 主模式）；② **任何模式只要需要联网核查关键声明**（第 7 步），都按本手册的核查步骤和三态标注来做。

## 一、AI 水分信号（只说“有迹象”，不断言“是 AI 写的”）

**铁规矩：只能说“有哪些 AI 生成的迹象”，不能说“这就是 AI 写的”。** 没有任何文字特征能确凿证明作者是谁。人也会写出这些毛病。

常见迹象：

| 迹象 | 描述 | 怎么写才稳妥 |
| :--- | :--- | :--- |
| **同义反复** | 同一个意思换几种说法反复出现 | “第 2–4 段表达的是同一个意思” |
| **无来源的权威背书** | “研究表明”“专家指出”“数据显示”，但不给出处 | “这几处说法都没有给出处，无法核查” |
| **过度工整的排比** | 对仗整齐但没有具体案例的三段式 | “排比很整齐，但每一条都没有具体例子” |
| **违背常识的因果拼接** | 把相邻的事实用“因此”硬连接 | “A 与 B 之间的因果关系，文中没有给出依据” |
| **空洞的升华** | 结尾拔高到“时代”“格局”，与正文无关 | “结尾的升华和正文论据对不上” |
| **数字过于整齐或无出处** | 大量整数、百分比，没有口径 | “数字没有口径与来源” |
| **标题留余地、正文断言** | 标题用问号或“或将”“疑似”留余地，正文却断言“已接到通知”“只是时间问题” | “标题用问号留了余地，正文却直接断言，两处语气对不上” |
| **虚构案例的痕迹** | 案例没有具体时间、地点、人名，或无法检索到 | “这个案例没有可查的细节” |

**正例**：“这篇文章有几处常见的 AI 生成痕迹（无出处的‘研究表明’三处；结论与论据对不上一处），但这些只是迹象，不能据此断定它是 AI 写的。”
**反例**：“这篇就是 AI 写的垃圾文。”
**反例二**：“这是一篇谣言式爆款文。”——“谣言”是定性；证据只支持“关键说法无出处、无法证实”，就写“关键说法无法证实的爆款文”。

## 二、提取并排序待核查的声明

不要核查一切。挑**最关键、可核查**的声明：

**可核查**：具体数字、日期、人物原话、机构报告、政策条款、法规名称、产品参数。
**不可核查**：纯观点、价值判断、预测（这些可以评论逻辑，但不是“核实”的对象）。

**优先级**（从高到低）：
1. 结论所依赖的关键数据；
2. 影响读者决策的数字（价格、收益、风险）；
3. 被引用的权威机构或人物原话；
4. 具体时间、事件。

**条数**：极速版不查；标准版 3 条；深度版 5–8 条。

## 三、核查步骤

1. 把声明改写成可搜索的**中立查询**——只用声明里的名词、数字、机构名；**不带画像信息、不带用户的任何个人情况**。
2. 优先找**一手来源**：机构官网、官方公告、原始论文、监管披露、权威媒体的原文。
3. 至少两个独立来源交叉比对更稳妥；只能找到一个就如实说。
4. **转述、二手报道不算一手**。如果只能找到二手，标注“依据二手来源”。
5. 记下**真实打开过的链接**。不得编造链接，不得凭记忆写“某某网站说……”却没有打开过。
6. 对比后给出三态标注。

**搜不到时**：“未找到可靠来源”，不是“这是假的”。

## 四、三态可信度标注（固定写法）

| 标注 | 条件 | 写法 |
| :--- | :--- | :--- |
| `[已核实]` | 与一手来源或权威报道一致 | `[已核实]`（来源：链接） |
| `[存疑/有出入]` | 与权威来源存在数字、时间或前提的偏差 | `[存疑/有出入]`（原文称 X，权威资料显示 Y，来源：链接） |
| `[未证实/单方说法]` | 找不到可靠第三方印证，仅为作者或发布方单方宣称 | `[未证实/单方说法]`（已搜索：……，未找到可靠来源） |

规则：

- “找不到来源”只能得到 `[未证实/单方说法]`，**不能**得到“假”；
- 写成 `[存疑/有出入]` 时，必须指出**具体差异**；
- 来源本身可疑时（匿名账号、营销号），不算一手来源。

## 五、没有联网能力时

- 所有声明统一标注“**未联网核查**”。**这时不打三态标签**：三态（已核实/存疑/未证实）表示“查过之后的结果”，没查就没有结果。把“未联网核查”和 `[未证实/单方说法]` 叠在一起，会让人误以为“已经搜过但没找到”；
- 需要让读者知道信息来源时，用事实描述代替标签，例如：“未联网核查（目前只有发布方自己的说法）”“未联网核查（这是你贴的内容里写的）”；
- 对扎实的材料同样如此：数字挂“未联网核查”即可，不要因为没查就暗示有疑点；
- 不要装作核查过；不要凭记忆给“已核实”；
- 可以提供“你可以自己去查的地方”（如官网、监管披露页、论文数据库），**但不能编造具体链接**；
- 在“可信度”一栏说明：“由于无法联网，以下判断仅基于文中逻辑和常识。”

## 五点五、涉及医疗、投资、法律时

本手册用于任何模式的核查时，**高风险边界同样适用**：只指出材料本身的可信度、风险点和该追问的问题，不替用户做“吃/不吃”“买/不买”“签/不签”的决定，并提示咨询持牌专业人士。

## 六、综合可信度怎么给

| 综合可信度 | 判断参考 |
| :--- | :--- |
| 高 | 关键声明大多已核实，没有明显矛盾 |
| 中 | 部分已核实，部分无法核实，没有明显矛盾；或材料不完整 |
| 偏低 | 关键声明存在出入，或关键声明几乎都无法核实，或逻辑自相矛盾 |

给一句理由。**“偏低”不等于“假”**，只是证据不足以支撑。

**没有联网时怎么给**（所有数字都只能写“未联网核查”，上表里“已核实”那一档用不上）：

| 材料情况 | 综合可信度 | 理由怎么写 |
| :--- | :--- | :--- |
| 内部自洽，没有矛盾，交代了限制与来源（如扎实的更新说明、写明局限的研究报道） | 高 | “文内自洽、交代了限制和来源；数字未联网核查” |
| 内部没有矛盾，也给出了部分口径或限制，但关键信息缺失（如发布稿没给测试条件、业绩稿没给口径） | 中 | “没有矛盾，但关键信息缺失” |
| 关键声明几乎都没有出处、没有口径、无法验证，或文内自相矛盾（拿不准在“中”和“偏低”之间时：宣传性内容里的关键数字全都没有口径，就选偏低；有风险提示和明确条件、只缺部分口径，选中） | 偏低 | “关键说法没有出处，无法验证” |

注意：这里的“高”是“看文本本身站得住”，不是“已经查实”。写理由时要带上“数字未联网核查”，别让读者以为查过了。信息不足以判断时给“偏低”并写明是“信息不足”，不是“有问题”。

## 七、示例（虚构；以下假设已联网搜索过）

**材料**：自媒体文章《震惊！这种食物正在悄悄毁掉你的肝》——“据权威研究，90% 的人每天都在吃这种‘毒食物’。专家指出，连续食用 3 天就会导致肝损伤。”

```markdown
## 一句话讲人话
这篇文章用了很吓人的标题和数字，但没给任何可查的出处，关键说法目前都无法核实。

## 核心事实（去水版）
- 文章称“90% 的人每天吃这种食物”。
- 文章称“连续食用 3 天会导致肝损伤”。
- 文章没有给出研究名称、机构、专家姓名。

## 滤镜拆解 / 潜台词
- **AI 水分/逻辑漏洞（只说迹象）**：
  - “据权威研究”“专家指出”各出现一次，都没有出处；
  - “90%”“3 天”两个数字没有口径或来源；
  - 标题的“震惊”与正文论据强度不匹配。
  这些是常见的低质量内容迹象，**不能据此断定是 AI 写的**。

## 可信度与事实核查
- **综合可信度**：偏低（关键声明无法核实）
- **关键点核查**：
  - “90% 的人每天吃”：`[未证实/单方说法]`（搜索“该食物 90% 食用比例”未找到权威来源）
  - “连续 3 天会导致肝损伤”：`[未证实/单方说法]`（未找到相关研究）

## 给你的建议
- **我的倾向**：不用被标题吓到。
- **结合你的情况**：如果你确实担心肝脏健康，建议咨询医生。这里不对该食物能不能吃下结论。
- **建议你再问清楚的问题**：
  1. 这项“权威研究”叫什么名字，发表在哪里？
  2. “90%”是哪个人群、怎么统计出来的？
```

# 讲人话规范、语气与输出模板

**什么情况下读我**：每次任务的最后一步（第 9 步）——写报告之前读。它决定怎么说话、报告长什么样。

## 一、讲人话的五条规矩

1. **结论先行**。第一句话就说清“这事到底是什么、核心结论是什么”。不要写“本文主要探讨了……”“这篇文章介绍了……”这类摘要腔。
2. **短句、口语、准确**。像懂行的朋友当面把事情讲清楚。一句话只放一个意思。
3. **翻译黑话**。专业术语、公文长难句、营销造词，换成普通人听得懂的说法；必要时用 1 句贴切的生活类比。一个类比说清就够，别连用。
4. **保真底线**。讲人话不能以歪曲原意、丢掉关键前提、制造情绪对立为代价。**核心数字、适用范围、限定条件必须留下。**“有条件成立”不能被讲成“一定成立”。
5. **深浅随人调整**。有画像且显示用户对这个领域熟，少解释术语；不熟，多用类比。没有画像就按“聪明的外行”来讲。

**正反例**

| 原文（虚构） | 摘要腔（反例） | 人话（正例） |
| :--- | :--- | :--- |
| 星河科技发布“云帆”手机，称其“续航行业领先，最高可达 72 小时”。 | 本文介绍了星河科技新发布的云帆手机，重点强调了其续航能力。 | 星河科技出了一款新手机“云帆”，主打续航。但“最高 72 小时”是什么条件下测的，原文没说。 |
| 公司本季度“持续优化组织结构，提升运营效率”。 | 公司在组织优化方面取得进展。 | 公司说要调整组织，但没说会不会裁员、哪些部门会变。 |

## 二、两种语气

### 平实直白（默认）

像朋友聊天，不嘲讽、不带情绪。

### 犀利吐槽

当次要求优先于可用画像的语气偏好；都没指定就平实。采用犀利语气时：

- 只吐槽**话术和做法**，不对具体的人做人身攻击；
- **只改措辞，不改内容**：事实、数字、可信度标注、结论倾向与平实版完全一致，也不升级指控（“证据弱就仍然用‘可能’”）；
- 吐槽要建立在已经列出的证据上，没证据的地方不吐槽；
- 吐槽优先用中性、可观察的描述（如“把店庆的频率说成了优惠的频率”）；“偷换”“故意”这类带意图色彩的词少用，用时必须能指到原文；
- **M1 官方通稿始终平实直白，但不替套话找补。** 直接说办事哪里变、哪里照旧；用户要求“挑字眼”时，用干脆平实的白话逐词拆开字面含金量（例如：“‘听取’只说听了，没说办得好不好；‘重申’只是照旧执行，没加新动作；‘按议程结束’就是例行散会”），不编内幕、不嘲讽、也不写“惯例上通常只是程序表述（存在例外）”这类绕嘴解释，更不先声明“我不用吐槽口吻”。

### 同一段内容的两种写法（事实完全一致）

**背景**：虚构的“云帆手机”发布稿。事实：原文称“续航行业领先，最高 72 小时”；没写测试条件，没写对比对象；价格没提；原文给出的屏幕参数和重量是明确的。

**平实版**
> 这款手机的续航宣传有一个数字（最高 72 小时），但没说怎么测的，也没说和谁比。价格也没提。屏幕和重量的参数写得很具体，这两项可以去规格表核对。

**犀利版**
> “最高 72 小时”，听着很猛，但怎么测的、和谁比的，一个字没写——这种数字先打个问号。价格也干脆没提。倒是屏幕和重量写得明明白白，这两项倒是能拿规格表逐项对。

对照：两版都包含同样的 4 条事实（有 72 小时数字、没说条件、没说对比、没提价格）和同一个倾向（续航条件不清、屏幕与重量可核对）。犀利版没有说“他们在骗人”，因为证据只能支持“没说明”。

**反例（犀利版越界）**：“72 小时纯属忽悠，厂商就是想骗你下单。”——这升级了指控，证据只支持“没说明条件”，不支持“骗”。

### 全篇犀利版示例（虚构，节选）

**背景**：“山语置业”开盘广告：“起价 12,000 元/㎡，距地铁 300 米，最后 20 席，错过再等一年！”起价没写对应哪栋哪层，300 米没写测量方式，席数没给依据。

> **一句话讲人话**
> 山语置业在催你今天抢房：“起价”没说是哪栋，“300 米”没说怎么量，“最后 20 席”不知道是谁数的。能当真的只有一件事：他们在卖房，而且希望你急。
>
> **事实与拆解**
> - **对方重点让你看的**：起价、地铁距离、稀缺感。“起价 12,000”——哪栋哪层、现在还有没有？“距地铁 300 米”——是直线还是走到入口？“最后 20 席”——谁数的？会不会每次开盘都“最后 20 席”？
> - **对方没有提到或一笔带过的**：起价对应的栋号楼层、交付标准与时间、物业费、地铁是已运营还是规划中。同类开盘广告通常会交代这些，每一项都影响你敢不敢签。
>
> **给你的建议**
> - **我的倾向**：先别急。广告给了三个没法下手的数字，你一个都抓不住。
> - **建议你再问清楚的问题**：起价房是哪栋哪层、还在不在？300 米是步行还是直线？地铁运营了没有，规划的话是哪一年的规划？

校准：吐槽全部落在“没写、没给依据”上，三个数字都引自原文；没有说“虚假宣传”“骗人楼盘”，因为证据只支持“没说明”。犀利版的事实、缺失清单、倾向与平实版完全一致，只是措辞更带刺。

## 三、输出模板

**总原则：像懂行的朋友面对面把事一次讲透，不要像交一份填表审计单。**
- **单一出现原则**：同一条数字、条件、风险或追问全篇只讲一次，禁止跨段落/跨小节复述。
- **短材料用自然段，长材料再用小节标题**：600 字以内的标准版（尤其是单段广告、价目表、逐句核查、短通稿）**优先用 2–4 个自然段直答**，不必强套 4 个固定 `##` 大标题；只有较长文章/发布会/深度拆解版才用 `##` 小节分层方便扫读。
- **行动与分界前置**：开头直接回答用户最关心的决定或给出最关键的一句问法；算得出分界线的直接报出全段账（如“5 次省 30、4 次打平、3 次以下按次更便宜”）。
- **只留影响决定的盲区，不倒检查清单**：场景卡是你的自查底稿，不是要全盘端给读者的清单。只写出真正影响当下决定的 2–3 个缺口，不硬凑“质保、耗材、闭店”等泛泛提醒。
- **不暴露内部术语与机械免责腔**：禁止出现“按消费销售拆”“M2/S2”等内部词；禁止机械复述题目约束（如“未联网、不补网址”）。离线短材料**不要写“由于无法联网，以下判断仅基于文中逻辑和常识”或“整体/综合可信度：中等”**这类机械尾注，而是把“这是商家自述/未查外部实测/缺什么细则”用半句自然人话融进判断里（如“以上都来自经销商自述，没查外部实测，整机价和退费细则还缺着”）。

### 标准版（默认，300–600 字）

按材料形态选最顺读的一种写法（都须守住核查、校准与隐私底线）：

**写法 A：短消费 / 选档 / 推广介绍（推荐用 3 个自然段，300–450 字精干直给，不强挂 H2 标题）**
- **第 1 段（结论 + 分界 / 先问哪句）**：一句话说清值不值得继续、先别急着付钱的原因；有明确选档问题时，开头直接给出能照搬发给店员/客服的核心问法，或用条款给出两端分界线。
- **第 2 段（把数字、条件和关键缺口一次说清）**：紧扣原文数字的真实前提、利益关系和最影响当下决定的 2–3 个盲区一次讲完，克制发散，不堆砌“质保/耗材/闭店”等泛泛提醒；同一数字只说一次，真实优点顺带承认。
- **第 3 段（个人套算 + 落地动作 + 自然边界收口）**：有画像时直接按用户情况套算并写明用了哪条前提（不混成产品事实）；给出具体可执行的试跑/核实步骤；末尾用半句自然人话交代数据来源边界即可（如“以上全按你贴的文字，没查外部实测”），**短材料离线一律不贴“综合/整体可信度：高/中/偏低”标签**。

**写法 B：逐句核查型（用户问“哪句话有根据 / 哪些真哪些假”）**
- 按原文顺序用编号 `1. 2. 3.` 逐句直答（开篇可省略或用 1 句总起，**不必在开头贴“整体可信度偏低”评级**）：每条先引原话，紧跟“有根据 / 缺证据 / 与记录冲突”的直观白话判断与证据边界；**材料本身带编号（如 E1–E4）时必须沿用原编号**，方便读者回查，且严格引用材料原名。联网核查时加 `[已核实]` / `[存疑/有出入]` / `[未证实/单方说法]` 与已读链接；离线仅据所附材料核对时，不强打联网三态标签。同源转引当场折叠；遇到并行混杂因素（同时改了两件事）只写“分不清各自作用，无法证实是唯一原因”，既不越界肯定也不越界否定。
- 末尾一句补齐转述保留口径和补查清单（若用户本就指定只按所附记录核对，直接说“以上仅据所附记录”，不必机械复述“未联网核查”或加“综合可信度”标签）。

**写法 C：长文章 / 重磅发布 / 通稿 / 热点（信息量大时用精简小节）**
```markdown
## 一句话讲人话
> 回答用户来问的那件事：谁在说、想让你做什么、结论卡在哪个关键条件上。

## 事实与拆解
（去水事实与滤镜/潜台词合并写清，每条信息只写一次；较长 M2 用“对方重点让你看的 / 没有提到或一笔带过的”两栏。）

## 核查与可信度
（联网只写实际核查的 1–3 条子声明与已读来源，末尾一句给综合可信度与具体缺口；离线一句带过“未联网核查”及离线判档理由，不凑长段。）

## 给你的建议
（第一句给最能改变决定的动作或问法；接着给倾向与个人适配，高风险领域只评材料不替用户做决定。）
```

**交付前按所选档位计数**：用户可见报告从结论到建议，按非空白可见字符计（含小标题、数字和标点，不含 Markdown 排版符号和链接地址）。超长先合并重复的数字、引文和追问，再删套话和次要背景；不要删关键限制、证据状态或高风险提示。读完一遍应能说出结论、最大限制和一个具体下一步。

**“谁在说、图什么”放哪里**：融入开头或事实段首句（如“这是听屿的会员年卡促销”），不另开小节；发布方没写明就写“发布方未标明”。

### 极速版（≤150 字）

用 **1 段自然短话**直接交付（不套 `**一句话** / **三条事实** / **建议**` 表单前缀），包含：
- 第一句直接说结论或办事变化（哪里变了、哪里照旧）；
- 紧接 1–3 个最关键的事实、字面拆解或限定条件；
- 最后一句给具体下一步，并用半句自然收口“未联网核查”（或末尾简注“未核查”）。

约束：
- 不做联网核查；仍守校准规则，没证据的负面判断不写，内容扎实直说扎实；
- 严禁车轱辘重复（如“没有新信号”和“全部照旧、没有新变化”别反复说三遍）；
- M1 例行通稿不公告“不用吐槽口吻”，不替套话找补，直接干脆拆出字面含金量与办事变化，不编内幕；
- 高风险也须在 150 字内点出具体风险、可核对的一步和专业边界。

### 深度拆解版（800–1500 字）

在标准版基础上增加：

- **原文证据对照**：关键判断旁边放原文引用（视频用时间点，如 `[01:24]`）；
- **横向对比**：和同类产品、上一期数据、行业常规做法的客观差异（有来源才写）；
- **待核实清单**：目前无法确认、需要继续查的点；
- 核查 5–8 条声明，不足不凑；补深度靠证据、条件和比较，不靠重复或杜撰。

### 内容很长时

先分段提炼再汇总，并在报告开头注明“内容较长，已分段处理”。不得只读开头就下全文结论。

### 视频内容额外说明

在正文事实段前加一行来源说明，如：“内容来自：平台自带字幕/语音转文字（可能有错字，人名和数字以原视频为准）/画面”。关键判断标时间点。

## 四、按模式写“事实与拆解”这一节

| 模式 | 这一节怎么写 |
| :--- | :--- |
| M1 官方通稿 | 写“实质信号与表述变化”，每条标“原文明确 / 惯例解读 / 无法判断”；例行通稿直接写“例行表态，没有明显新信号”，点明办事哪里照旧、哪里改了 |
| M2 利益方话术 | 较长材料用两栏：**对方重点让你看的**（真亮点如实写进这栏）/ **对方没有提到或一笔带过的**；短消费/选档材料可直接合栏成“条款要点与盲区”，同一数字全篇只写一次 |
| M3 AI 洗稿 / 幻觉 | 写“水分与逻辑漏洞”：有哪些 AI 生成的迹象（只说迹象，不断言）；哪些说法没有来源 |
| M4 深度脱水 | 写“论证骨架”：主张 → 论据 → 结论，并带上作者的限定条件；末尾写“读完能带走什么”和“值不值得读原文” |
| M5 社媒热点 | 写“时间线 + 三分”：已证实的事实（离线改作“帖子里可见的事实（未联网核查）”）/ 单方说法 / 情绪与立场；事件未落地写“截至目前” |
| 辅模式 | 主模式写完整，辅模式补充最重要的 1–3 条，不重复 |

内容扎实、没什么可挑的时：这一节写一两句“这篇基本实在”和理由，不凑槽点。

## 五、“给你的建议”怎么写

### 有画像

- 在“结合你的情况”里写具体建议，并**注明用了画像的哪一条**，例如：“按你说的预算在 3000 元以内，这款超了一档……”；
- 只影响这一节和解释深浅，**不能**因此改变前面的事实、拆解和可信度；
- 不迎合：用户倾向买某品牌，也不能弱化风险提示；
- “在办的事”超过 90 天，先确认是否还有效再用。

### 没有画像

（报告里不需要写“（无画像）”这几个字，直接按人群写即可。）

“结合你的情况”改成按人群给通用建议：

> - 如果你是**正想换手机的普通用户**：……
> - 如果你是**对续航很敏感的人**：……
> - 如果你只是**看热闹**：不用管。

同文不同画像的保险示例见 `user-profile.md` 第四节；不要从所贴广告反推读者身份、预算或购买意向。

### 其他情况

- 没有已知的个人关联：可以写“如果你只是了解行业动态，知道这点就够了”，不替用户断言与他无关；
- 高风险领域（医疗、投资、法律）：建议只写风险点和该追问的问题，不替用户做最终决定，不说“买/不买”“吃/不吃”，并提示咨询持牌专业人士。

## 六、写完前过一遍

- 第一句话是结论吗？
- 在本档字数内，关键数字、范围、限定条件及必要风险是否都留下了？
- 有没有出现外行看不懂的词没解释？
- 语气有没有超过证据强度？（校准在第 8 步已经做过，这里只是最后确认没有写走样。）
- 视频类：有没有说明内容来源和可能的错字？

# 解码校准：防“尬黑”、防“听床”

**什么情况下读我**：每次任务的第 8 步，写报告之前做自检时读。解码很容易走偏成两种毛病——把正常内容挑出一堆刺（尬黑），或者把例行通稿编成大戏（听床）。本手册是刹车。

## 一、六条通用规则（所有模式）

### 1. 每个负面判断都要挂证据

证据可以是：原文引用、数字对比、外部来源。**挂不上证据的，只能写成“建议追问的问题”，不能写成结论。**

- 反例：“这个产品肯定有隐藏费用。”
- 改写：“原文没有提到续费价格。建议问：第二年起每年多少钱？”

### 2. “没提”不等于“隐瞒”

只有同时满足两点，才把“缺席的信息”列入盲区：① 同类内容通常会披露；② 它会影响读者的决策。措辞用“没有提到”。只有拿到证据表明对方**刻意**回避（比如被明确问到却绕开），才能用“回避”。

- 反例：“公司隐瞒了研发投入。”（一份产品海报没写研发投入，这很正常。）
- 改写：不列入盲区。——海报通常不披露研发投入，也不影响购买决策。
- 反例：“报告没写价格，说明对方在躲。”
- 改写：“发布稿没有提到价格。同类发布稿通常会写起售价，建议查官方定价页。”

### 3. 红旗词只触发追问，不直接定性

“行业领先”“最高”“全面超越”“限时”“稳健”这些词是**提醒你去查**，不是罪证。查清对比对象和测试条件后再下判断；查不到，就写“对比对象不明”。

### 4. 优点如实写

真实的进步和亮点要承认。**不设槽点数量要求**，不为显得犀利硬找槽点。原文扎实时，结论就是“这篇基本实在”。

### 5. 语气不超过证据强度

证据弱用“可能”“尚不清楚”“原文没说明”，证据强才用肯定句。犀利语气只改措辞，不升级指控。

| 证据强度 | 可用的说法 |
| :--- | :--- |
| 原文自相矛盾、或与权威来源直接冲突 | “原文这两处对不上”“与官方数据不符” |
| 有迹象但无直接证据 | “可能”“有这种迹象，但不能确定” |
| 只是缺信息 | “原文没说明”“尚不清楚” |

### 6. 输出前自检（三个问题）

1. **每条批评都有证据吗？** 没有的，降级成追问，或删除。
2. **把结论反过来说，现有证据是否同样支持？** 是的话，说明证据不足，要降级为“存疑”。
   - 例：结论“这数据可能被挑选过”，反过来“这数据没被挑选过”——如果现有材料对两种说法同样适用，就写成“存疑，建议追问样本选取方式”。
3. **有没有把自己的推测写成了事实？** 有，改成“可能”，或删掉。

## 二、官方通稿（M1）专项五条

1. **三级标注**：每个解读标注为 ① 原文明确；② 惯例解读（基于公开可查的表述惯例，并注明依据）；③ 无法判断。**不存在“内幕”这一级。**
2. **说“表述变了”必须有对照原文**：拿到上一次同类文件的原文，并引用差异，才能说“新增”“删除”“改动”。拿不到，就写：“未找到可对照的上一版，无法判断是否为新提法。”
3. **信号词对照是惯例，不是定律**：用“通常意味着”，并提示存在例外。
4. **禁区**：不推测人事变动、内部分歧、个人动机、未公开的会谈内容；不预测具体政策的出台时间；不把无法核实的“知情人士”类说法当依据。
5. **落脚点是对普通人的实际影响**，不是“谁赢了谁输了”。例行通稿就直接说：“例行表态，没有明显新信号。”

## 三、高风险领域边界（医疗、投资、法律）

- 可以：指出风险点、缺失的信息、该追问的问题；评价这份**宣传材料本身**的可信度。
- 不可以：替用户做最终决定（“这只基金买不买”“这个药吃不吃”“这个合同签不签”）。
- 要提示：重要决定请咨询持牌专业人士。
- 倾向必须能从前文事实和核查结果推出，不能凭印象。

## 四、反面示例 → 改写

### 示例 1：尬黑（把正常内容挑出刺）

**材料（虚构）**：某款“青禾”记账软件的更新说明，列出了 5 项新功能和 2 个已知问题，并写明“部分功能仅 Pro 版可用，价格见官网”。

- **反面输出**：“更新说明避重就轻，把 Pro 功能放进更新里是在诱导付费；没写 Pro 价格说明藏着掖着。”
- **问题**：说明里已经交代了“部分功能仅 Pro 版”并指向官网；已知问题也如实写了。这是实在的写法，上面全是推测。
- **改写**：“这份更新说明比较实在：新功能列得清楚，已知问题也写了，还说明了哪些功能要付费。唯一没在文里写的是 Pro 的具体价格，官网可查。基本实在，没什么可挑的。”

### 示例 2：听床（把例行通稿编成大戏）

**材料（虚构）**：某地方政府会议新闻：“会议强调，要坚持稳中求进，进一步做好安全生产、民生保障等各项工作，抓好各项任务落实。”

- **反面输出**：“‘进一步做好’说明此前这方面工作不到位，暗示近期可能有人事调整，背后可能存在内部分歧。”
- **问题**：把常规表态当成“批评”，并推测人事和内部分歧，这是禁区；没有任何对照原文或证据。
- **改写**：“这是例行表态，列的都是常规工作方向，没有明显新信号。如果你想判断它是否‘新提法’，需要拿到该地上一次同类会议的原文对照；我这里没有，所以无法判断。”

### 示例 3：证据不足却下结论

**材料（虚构）**：一篇文章说“某品牌防晒霜经检测防晒值 SPF 80”，没有给检测机构。

- **反面输出**：“这个数据是假的。”
- **改写**：“文中没给检测机构和报告，目前无法验证（没联网查过，就写‘未联网核查’；联网查过仍找不到，才标 `[未证实/单方说法]`）。建议追问：检测由谁做的，能否看到报告编号？”

### 示例 4：犀利语气升级了指控

- **反面输出**：“人家就是想割你韭菜。”
- **改写**（犀利但不超证据）：“‘最高收益’四个字写得很大，‘历史业绩不代表未来’写得很小——这个排版的意思，你自己品。”（陈述的是原文呈现方式，没有断言动机。）

## 五、出口检查清单（写完报告前逐条勾）

- [ ] 每条负面判断后面能指出证据（引用、数字、来源）？
- [ ] “没提”的信息，满足“同类通常披露 + 影响决策”吗？措辞是“没有提到”而不是“隐瞒”？
- [ ] 红旗词是否只触发了追问？
- [ ] 真实的优点写了吗？有没有为了显得犀利硬凑槽点？
- [ ] 把结论反过来说，证据是不是同样成立？成立就降级。
- [ ] 肯定句的证据足够强吗？不够就改成“可能”“尚不清楚”。
- [ ] 推测有没有被写成事实？
- [ ] M1：有没有写“新增/删除”却没有对照原文？有没有碰人事、分歧、动机、时间预测？
- [ ] 高风险领域：有没有说“买/不买”“吃/不吃”“签/不签”？
- [ ] 内容本身没问题时，结论是否就是“基本实在 / 例行表态，没有明显新信号”？

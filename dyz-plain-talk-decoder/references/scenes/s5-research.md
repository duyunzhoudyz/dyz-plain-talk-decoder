# S5 研究与数据包装

**什么情况下读我**：内容是论文的新闻稿、“研究表明”类科普、行业白皮书、榜单与排名。发布者想让你**相信结论，进而相信背后的产品或机构**。读之前应已读过通用五问手册。若是研究者自己发表、没有产品或购买诉求的论文类内容（主模式为 M4），也可以借用下面的检查清单核对样本、因果和效果大小，但不走“对方想让你做什么”的两栏。

> **高风险领域**：涉及医疗健康、投资时，只讲风险点和该追问的问题，评价“这份材料本身”的可靠性，不替用户做最终决定，并提示咨询专业人士。

## 检查清单（后台自查雷达：只挑真正影响当下判断的 2–3 个关键缺口写进报告，不整表倒给读者）

| # | 检查项 | 要看什么 |
| :--- | :--- | :--- |
| 1 | **样本量、周期、两层分母与代表性** | 多少人/多少样本？周期多长（几周的时间够不够观察到宣称的效果）？怎么选的（自愿参与、特定人群、网络问卷）？**遇自愿回卷或抽样调查时，主动算清两层分母——回卷中占比（正面反馈数 / 回收数）与全体受邀者中占比（正面反馈数 / 受邀总数）**，并做双向边界提醒：前者不能当成“实际有效率”或“你自己用了有效的概率”；未回卷者也不能统统算作无效，故后者同样不是实际改善率。**明确区分两层代表性断点**：自选样本/自愿回卷者 ≠ 全体受邀者，老客户/特定重度用户 ≠ 全体普通使用者；同时区分“主观感受自报”与“客观实测数据” |
| 2 | **相关还是因果** | “与……有关”“更可能”还是“导致”“能够”？研究设计能否支持因果（有无对照、随机化）？ |
| 3 | **发表与评审** | 是否发表在同行评议的期刊？是预印本还是会议报告？还是企业自己的报告？ |
| 4 | **资助方与利益冲突** | 谁出的钱？研究者与产品是否有关联？是否披露？ |
| 5 | **新闻稿 vs 论文原文** | 新闻稿的结论是否比原文夸大？限定条件（人群、剂量、时间）是否丢失？ |
| 6 | **效果大小** | “提高 50%”是绝对变化还是相对变化？从多少涨到多少？ |
| 7 | **榜单与白皮书规则** | 评选标准、权重、数据来源、主办方、是否收费入选 |
| 8 | **可重复性** | 是否有其他独立研究印证？ |
| 9 | **稳妥之处** | 样本充分、设计扎实、限定条件写清、利益披露完整的——要承认 |

## 常见话术与对应追问

| 话术 | 通常需要弄清的 | 可以追问 |
| :--- | :--- | :--- |
| “研究表明……” | 哪项研究、谁做的 | “具体是哪篇论文？发表在哪里？” |
| “有效率达 90%” | 对照组、样本量、有效的定义 | “对照组是什么？多少人参加？怎样算有效？” |
| “问卷显示 X% 客户觉得有效/有改善” | 回收率、两层分母、自选样本与客观测量 | “一共发了多少份、收回多少份？按全体受邀者算占比是多少？有没有独立客观实测，而不是只靠老客户主观勾选？” |
| “风险降低 50%” | 相对还是绝对 | “从百分之几降到百分之几？” |
| “某某白皮书显示……” | 主办方与数据来源 | “谁出的钱？数据怎么来的？” |
| “荣登 XX 榜单第一” | 评选规则 | “评选标准是什么？是否需要付费或申请？” |
| “专家指出” | 哪位专家，是否有利益关系 | “是谁？和产品是否有关联？” |

## 独立验证路径

只向发布方要数据不构成验证——发布方与结论往往利益相关。至少给用户一个不依赖发布方的出口：

- 行业数据、榜单、白皮书：统计局、商务部门等官方公开数据；其他城市/机构**同口径**的横向对比；
- 论文类：论文数据库与期刊官网查原文，看结论与新闻稿是否一致；
- 健康功效：监管部门的批准信息与独立研究，不以资助方说法为准。

联网搜索后找不到，才说“未找到独立来源”；离线禁打三态，用主语自然归因并把查原文/监管披露写成下一步动作，不声称搜过。

## 完整示例（全部虚构）

**材料**：新闻稿——“清远大学研究团队最新研究表明，每天饮用‘山泉元气饮’可使成年人睡眠质量提升 40%。研究共纳入 36 名志愿者，为期 4 周，研究由山泉食品公司资助。”

**分类**：M2 + S5（涉及健康）；M3 作辅模式，用于核查原论文。

**输出（标准版，平实语气，离线自然段直答）**

> 单看这份说“山泉元气饮能让睡眠质量提升 40%”的新闻稿，眼下不足以证明喝它真管用——研究规模很小、由品牌方出钱，最关键的对照组、计分方式和论文出处全没写。
>
> 稿子如实交代了 36 名志愿者、4 周周期和山泉食品资助，这本身不是造假证据，但小样本加短周期不足以外推到所有成年人，也不能直接当成你自己喝了同样有效的概率。更重要的是，原文没说有没有设对照组（不喝或喝安慰剂的人怎么变），也没说“提升 40%”是用主观睡眠问卷打分还是客观监测仪器测的、原始分从多少涨到多少——相对提高四成，不等于每个人多睡四成。
>
> 别单听品牌方转述，想核实就向发布方要完整论文题名，自己去期刊官网或论文数据库查原文：核对随机分组对照、绝对改善幅度，以及有没有其他独立研究团队重复出同类结果。如果长期睡不好，建议带具体症状咨询执业医生，别把饮品宣传当治疗方案。

**这个示例体现的校准点**：没有说“研究造假”“软文骗人”；只按事实指出证据不足的缺口，不硬贴“综合可信度”标签；没有替用户决定喝不喝；给出了“睡眠问题咨询医生”的提示；给了不依赖发布方的独立验证出口（查论文原文），而不是只向发布方追问。

# S5 研究与数据包装

**什么情况下读我**：内容是论文的新闻稿、“研究表明”类科普、行业白皮书、榜单与排名。发布者想让你**相信结论，进而相信背后的产品或机构**。读之前应已读过通用五问手册。若是研究者自己发表、没有产品或购买诉求的论文类内容（主模式为 M4），也可以借用下面的检查清单核对样本、因果和效果大小，但不走“对方想让你做什么”的两栏。

> **高风险领域**：涉及医疗健康、投资时，只讲风险点和该追问的问题，评价“这份材料本身”的可靠性，不替用户做最终决定，并提示咨询专业人士。

## 检查清单

| # | 检查项 | 要看什么 |
| :--- | :--- | :--- |
| 1 | **样本量与代表性** | 多少人/多少样本？怎么选的（自愿参与、特定人群、网络问卷）？ |
| 2 | **相关还是因果** | “与……有关”“更可能”还是“导致”“能够”？研究设计能否支持因果（有无对照、随机化）？ |
| 3 | **发表与评审** | 是否发表在同行评议的期刊？是预印本还是会议报告？还是企业自己的报告？ |
| 4 | **资助方与利益冲突** | 谁出的钱？研究者与产品是否有关联？是否披露？ |
| 5 | **新闻稿 vs 论文原文** | 新闻稿的结论是否比原文夸大？限定条件（人群、剂量、时间）是否丢失？ |
| 6 | **效果大小** | “提高 50%”是绝对变化还是相对变化？从多少涨到多少？ |
| 7 | **榜单与白皮书规则** | 评选标准、权重、数据来源、主办方、是否收费入选 |
| 8 | **可重复性** | 是否有其他独立研究印证？ |
| 9 | **稳妥之处** | 样本充分、设计扎实、限定条件写清、利益披露完整的——要承认 |

## 常见话术与对应追问

| 话术 | 通常需要弄清的 | 可以追问 |
| :--- | :--- | :--- |
| “研究表明……” | 哪项研究、谁做的 | “具体是哪篇论文？发表在哪里？” |
| “有效率达 90%” | 对照组、样本量、有效的定义 | “对照组是什么？多少人参加？怎样算有效？” |
| “风险降低 50%” | 相对还是绝对 | “从百分之几降到百分之几？” |
| “某某白皮书显示……” | 主办方与数据来源 | “谁出的钱？数据怎么来的？” |
| “荣登 XX 榜单第一” | 评选规则 | “评选标准是什么？是否需要付费或申请？” |
| “专家指出” | 哪位专家，是否有利益关系 | “是谁？和产品是否有关联？” |

## 完整示例（全部虚构）

**材料**：新闻稿——“清远大学研究团队最新研究表明，每天饮用‘山泉元气饮’可使成年人睡眠质量提升 40%。研究共纳入 36 名志愿者，为期 4 周，研究由山泉食品公司资助。”

**分类**：M2 + S5（涉及健康）；M3 作辅模式，用于核查原论文。

```markdown
## 一句话讲人话
一则新闻稿说某款饮料让睡眠质量提升 40%。但研究只有 36 个志愿者、为期 4 周，并且由饮料公司出资，现在这个结论只能算“初步线索”，不足以说“喝它能改善睡眠”。

## 核心事实（去水版）
- **结论**：新闻稿称，每天饮用该饮料睡眠质量提升 40%。
- **样本**：36 名志愿者，4 周。
- **资助**：饮料所属公司出资。
- **缺失**：没有写对照组、没有说“40%”如何衡量、没有给论文出处。

## 滤镜拆解 / 潜台词
- **对方重点让你看的**：“大学研究团队”“提升 40%”。
- **对方没有提到或一笔带过的**：
  - 有没有喝普通饮料或不喝的对照组；
  - “睡眠质量”是用问卷主观打分，还是用设备测量；
  - 40% 是相对变化，具体从多少到多少；
  - 论文发表在哪里，是否经过同行评议。
  科普类新闻稿通常会写明论文出处和设计，这些都影响结论的可信度。
- **规模提示**：36 人样本很小；资助方与产品相关。这两点本身不说明研究造假，但意味着结论需要更大规模、独立来源的研究来印证。

## 可信度与事实核查
- **综合可信度**：偏低（只能说明证据不足，不能说明研究不真实）
- **关键点核查**：
  - 36 人、4 周、公司资助：未联网核查（新闻稿自述，未核对论文原文）
  - “睡眠质量提升 40%”：未联网核查（新闻稿没写对照组和衡量方式）

## 给你的建议
- **我的倾向**：先别急。这份材料不足以支持“喝了能改善睡眠”。
- **结合你的情况**：如果你是长期睡不好的人，睡眠问题建议先咨询医生，而不是依赖一款饮料；如果你只是好奇，不用管。这里不对是否饮用做建议。
- **建议你再问清楚的问题**：
  1. 论文发表在哪里？有没有对照组？
  2. “40%”是怎么衡量的，从多少变成了多少？
  3. 有没有不受该公司资助的独立研究得出类似结果？
```

**这个示例体现的校准点**：没有说“研究造假”“软文骗人”；“偏低”的理由是证据不足，不是欺骗；没有替用户决定喝不喝；给出了“睡眠问题咨询医生”的提示。

# S1 产品发布与营销

**什么情况下读我**：内容是新品发布会、产品官宣、功能更新公告、软文广告。发布者想让你相信“这个产品领先”，并下单或试用。读之前应已读过通用五问手册。

## 检查清单

| # | 检查项 | 要看什么 |
| :--- | :--- | :--- |
| 1 | **绝对化用语** | “行业领先”“全面超越”“史上最强”：对比对象是谁？测试集和评测方法是自选的还是公开通用的？ |
| 2 | **极值数字** | “最高提升 300%”“低至 XX 元”“长达 XX 小时”：在什么测试条件、哪个版本、哪种配置下得到的？典型值是多少？ |
| 3 | **自造概念** | 品牌自创的名词，翻译成行业通用说法是什么？有没有可对比的通用指标？ |
| 4 | **价格与成本** | 起售价对应哪个版本？实际常用配置多少钱？有无订阅、耗材、配件等持续成本？ |
| 5 | **限制条件** | 开源协议、硬件门槛、上市时间、地区限制、是否需要登录/订阅账号 |
| 6 | **对比的公平性** | 对比的是自家上一代还是竞品？竞品是当前最新型号还是老款？ |
| 7 | **真实亮点** | 有具体数字、可验证、可复现的改进——要承认 |

## 常见话术与对应追问

| 话术 | 通常需要弄清的 | 可以追问 |
| :--- | :--- | :--- |
| “续航行业领先” | 对比对象、测试方式 | “续航是按什么标准测的？和哪款机型比？日常使用能撑多久？” |
| “性能提升 40%” | 哪项性能、对比哪一代、测试软件 | “是哪个跑分/任务上的 40%？对比的是哪代？” |
| “最高支持 XX” | “最高”对应哪个配置 | “标准版支持多少？最高那一档要多花多少钱？” |
| “AI 全新升级” | 具体新增了什么功能 | “具体多了哪几个功能？没有 AI 之前做不到的是什么？” |
| “即将上市/敬请期待” | 没有日期就没有承诺 | “什么时候能买到？哪些地区？” |

注意：这些只触发追问，不是定罪。追问之后结论才能落下来。

## 完整示例（全部虚构）

**材料**：星河科技发布会稿节选——“‘云帆 X’手机，搭载自研‘天枢’芯片，性能行业领先；续航最高可达 72 小时；全新‘灵境’影像系统，夜景提升 3 倍。屏幕 6.7 英寸，重量 188 克。预售即将开启。”

**分类**：M2 + S1。

**输出（标准版，平实语气）**

```markdown
## 一句话讲人话
星河科技发了一款新手机“云帆 X”，宣传亮点是性能、续航和夜景拍照；但几个关键数字没说明条件，价格也没提，现在还没法判断它到底值不值。

## 核心事实（去水版）
- **明确的参数**：屏幕 6.7 英寸，重量 188 克。
- **宣传的数字**：续航“最高 72 小时”，夜景“提升 3 倍”。
- **自研芯片**：叫“天枢”，原文称“性能行业领先”。

## 滤镜拆解 / 潜台词
- **对方重点让你看的**：自研芯片、72 小时续航、夜景 3 倍、屏幕和重量（后两项有具体数字，可当真）。
- **对方没有提到或一笔带过的**：
  - “最高 72 小时”的测试条件，以及典型使用时长；
  - “夜景提升 3 倍”是和哪一款、用什么指标比；
  - “性能行业领先”的对比对象和测试项目；
  - 起售价和上市日期（原文只说“预售即将开启”）。
  同类发布稿通常会交代价格和对比对象，所以这几项值得问。

## 可信度与事实核查
- **综合可信度**：中（参数部分明确，宣传数字缺条件）
- **关键点核查**：
  - 屏幕尺寸、重量：未联网核查（建议以官网规格页为准）
  - “续航最高 72 小时”：未联网核查（目前只有发布方自己的说法，没有测试条件）
  - “夜景提升 3 倍”：未联网核查（目前只有发布方自己的说法，对比对象不明）

## 给你的建议
- **我的倾向**：先别急。发布稿里的关键数字缺条件，价格未知，等第三方实测和官方价格出来再看。
- **结合你的情况**：如果你正打算换手机、看重续航，等实测；如果只是看看新闻，不用管。
- **建议你再问清楚的问题**：
  1. 72 小时是什么条件下测的？日常使用大概多久？
  2. 夜景“3 倍”对比的是哪款手机、哪项指标？
  3. 起售价是哪个配置？什么时候、哪些地区能买到？
```

**这个示例体现的校准点**：真亮点（屏幕、重量）写进“重点让你看的”；价格、对比对象属于“同类通常披露且影响决策”所以列入“没有提到”；没有说“夸大”“忽悠”，只说“没有说明”。

# S1 产品发布与营销

**什么情况下读我**：内容是新品发布会、产品官宣、功能更新公告、软文广告。发布者想让你相信“这个产品领先”，并下单或试用。读之前应已读过通用五问手册。

## 检查清单

| # | 检查项 | 要看什么 |
| :--- | :--- | :--- |
| 1 | **绝对化用语** | “行业领先”“全面超越”“史上最强”：对比对象是谁？测试集和评测方法是自选的还是公开通用的？ |
| 2 | **极值数字** | “最高提升 300%”“低至 XX 元”“长达 XX 小时”：在什么测试条件、哪个版本、哪种配置下得到的？典型值是多少？**总量口径是否含配件**（如耳机“续航 40 小时”是单耳还是含充电盒总续航；电源“XX Wh”是电芯容量还是额定输出、含不含扩展电池包）？电池循环寿命类数字还要问充放电倍率与衰减阈值（循环多少次后容量保持率多少算寿命终点）。数字有没有对比对象（和谁比提升/降噪）？**“已售 X 台”“X+ 人支持”类销量/支持数要问构成口径**：按台还是按人、含不含配件、上代产品、未付款订单。 |
| 3 | **自造概念** | 品牌自创的名词，翻译成行业通用说法是什么？有没有可对比的通用指标？ |
| 4 | **价格与成本** | 起售价对应哪个版本？实际常用配置多少钱？有无订阅、耗材、配件等持续成本？**涉及定金/锁位/满减抵扣时，必须核对最终到手总价**（确认售价不变且抵满才算净省，防售价变动吃掉优惠） |
| 5 | **限制条件** | 开源协议、硬件门槛、上市时间、地区限制、是否需要登录/订阅账号；**“预售/锁位”要追问从预售到实际发货的间隔、延迟发货怎么办/责任怎么算、没排上/未到店/试完不买能否退费**，以及售价对应哪个配置；“前 X 名”“限量 X 件”要追问排位与计数依据（按登记、下单还是付款，付钱前能否确认排上、分不分型号） |
| 6 | **对比的公平性** | 对比的是自家上一代还是竞品？竞品是当前最新型号还是老款？ |
| 7 | **真实亮点** | 有具体数字、可验证、可复现的改进——要承认 |

## 常见话术与对应追问

| 话术 | 通常需要弄清的 | 可以追问 |
| :--- | :--- | :--- |
| “续航行业领先” | 对比对象、测试方式 | “续航是按什么标准测的？和哪款机型比？日常使用能撑多久？” |
| “性能提升 40%” | 哪项性能、对比哪一代、测试软件 | “是哪个跑分/任务上的 40%？对比的是哪代？” |
| “最高支持 XX” | “最高”对应哪个配置 | “标准版支持多少？最高那一档要多花多少钱？” |
| “AI 全新升级” | 具体新增了什么功能 | “具体多了哪几个功能？没有 AI 之前做不到的是什么？” |
| “即将上市/敬请期待” | 没有日期就没有承诺 | “什么时候能买到？哪些地区？” |

这些是后台自查雷达，不是定罪书，也不要整张清单倒给读者——只挑真正影响当下决定的 2–3 个关键缺口写进报告。型号、单位、测试样本、基线与条件要对应原材料；只有最高值就不要报日常值。若还要求付款、交锁位费或领取限时权益，按通用手册同时读 S2，不拿参数清单代替交易核对；**混合材料写作时同一议题一次讲完绝不中途回跳**——性能口径、推荐方利益关系（有返佣/服务费不等于实测造假）与按自身习惯试机一段闭环，优惠净省前提、名额排位、最终到手总价与退费书面规则下一段闭环。

## 完整示例（全部虚构）

**材料**：星河科技发布会稿节选——“‘云帆 X’手机，搭载自研‘天枢’芯片，性能行业领先；续航最高可达 72 小时；全新‘灵境’影像系统，夜景提升 3 倍。屏幕 6.7 英寸，重量 188 克。预售即将开启。”

**分类**：M2 + S1。

**输出（标准版，平实语气，离线自然段直答）**

> 单看这份厂商发布稿节选，如果你在观望“云帆 X”，眼下还判断不了日常好不好用，先别急着冲预售——几个最吸睛的数字都没写测试条件，也没报起售价、版本差异和具体开售日期。
>
> 屏幕 6.7 英寸、重量 188 克和自研“天枢”芯片是明确给出的硬件规格，可以直接去官方参数页核对。但“续航最高 72 小时”只是特定工况下的极值，不是日常典型续航，稿里没写测试时的屏幕亮度、网络环境和负载；“性能行业领先”和“夜景提升 3 倍”也没交代和哪款机型比、测的是哪项指标，“灵境影像系统”也只是品牌自造名称，没有对应的镜头传感器或成片指标，拿这些话换算不出日常体验。
>
> 真打算买，等正式配置表和预售规则出来后，先查第三方日常实测，并重点核清三件事：常用存储版本卖多少钱、标准版连续亮屏的日常续航能撑多久，以及“夜景 3 倍”对比哪款机型、同场景暗光样张和细节表现到底怎么样。

**校准点**：承认厂商列出了屏幕和重量，不把列出参数等同于独立实测；短材料用自然段按议题一次讲清，不套 H2 表单壳也不硬贴“综合可信度”标签。“即将预售”没有交易条件，这里不强加第二张卡。

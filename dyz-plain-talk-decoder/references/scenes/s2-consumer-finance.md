# S2 消费与金融销售

**什么情况下读我**：内容是保险、理财、基金产品的说明或宣传；课程与知识付费广告；保健品、医美宣传；楼盘广告；带货种草的软文。发布者想让你**掏钱，而且尽快掏钱**。读之前应已读过通用五问手册。

> **高风险领域**：涉及投资、医疗健康、法律时，只指出风险点和该追问的问题，评价“宣传材料本身”的可信度，**不替用户做最终决定**（不说买/不买、吃/不吃），并提示咨询持牌专业人士。

## 检查清单

| # | 检查项 | 要看什么 |
| :--- | :--- | :--- |
| 1 | **收益是保证还是演示** | “预期收益”“演示收益”“历史年化”：写的是合同保证的，还是假设的、过去的？ |
| 2 | **历史业绩的取样** | 选的是哪段区间？只给最好阶段，还是全周期？有没有同类平均作对照？ |
| 3 | **全部费用** | 手续费、管理费、托管费、佣金、退出或退保损失、续费价格、隐含的“需要再买的东西” |
| 4 | **免责条款与小字** | 除外责任、等待期、免赔额、赔付条件、不适用情形 |
| 5 | **适用与不适用人群** | 谁适合？谁不适合？ |
| 6 | **紧迫感是否真实** | “限时”“限量”“最后 X 个名额”：有没有截止时间、是否反复出现、倒计时是否每次重置 |
| 7 | **是否为未标注的广告** | 种草内容是否有“广告/合作”标注；作者是否与商家有利益关系 |
| 8 | **功效与资质** | 保健品、医美的功效声明：有无批准文号或资质？有无试验证据？是否把“辅助”说成“治疗” |
| 9 | **成功案例与好评率的代表性** | “学员月入过万”“客户收益 30%”“98% 家长表示进步明显”：是个例还是普遍？多少人、怎么问的、“进步”指什么？样本是否挑选 |
| 9b | **排名与奖项** | “同类排名前 5%”“荣获 XX 奖”：由谁排、哪一类、截至哪天、共有多少同类？如内容主体就是榜单，再读 S5 |
| 10 | **真实亮点** | 条款清晰、费用透明、风险提示完整的，要承认 |

## 常见话术与对应追问

| 话术 | 通常需要弄清的 | 可以追问 |
| :--- | :--- | :--- |
| “预期年化 6%” | 是否保证、从何而来 | “这 6% 是合同保证的吗？不达预期会怎样？” |
| “历史最高收益 35%” | 区间选择、平均水平 | “近 5 年每一年的收益分别是多少？同类平均呢？” |
| “零手续费” | 其他费用是否转移 | “管理费、赎回费、续费价格分别是多少？” |
| “限时优惠，仅剩 3 个名额” | 真实性 | “优惠截止日期是哪天？之后价格是多少？” |
| “学员平均月入过万” | 统计口径 | “这是多少学员的平均？是所有学员还是其中成功的？” |
| “纯天然，无副作用” | 证据与资质 | “有批准文号吗？有哪些试验支持？谁可以不吃？” |
| “以合同条款为准” | 关键条款是什么 | “请把免责条款和退保规则的具体页码给我看。” |

## 完整示例（全部虚构）

**材料**：“安康福”终身重疾险宣传页——“确诊即赔，**保额 50 万**！30 岁男性每年仅需 **3,980 元**起！累计返还，**最高可返还已交保费的 150%**！限时 3 天，名额有限！”

**分类**：M2 + S2（高风险：保险）。

```markdown
## 一句话讲人话
这是一份重疾险的宣传：确诊特定疾病后赔 50 万，30 岁男性每年 3,980 元起。宣传的重点是“确诊即赔”“最高返还 150%”，但哪些病算、什么情况下不赔、返还要满足什么条件，这页上都没写清楚。

## 核心事实（去水版）
- **产品**：终身重疾险，基础保额 50 万。
- **价格**：30 岁男性每年 3,980 元“起”（具体档位、缴费年限没写）。
- **返还**：“最高”返还已交保费的 150%（返还条件没写）。
- **促销**：限时 3 天，名额有限。

## 滤镜拆解 / 潜台词
- **对方重点让你看的**：确诊即赔、50 万保额、低门槛价格、最高返还 150%、限时。
- **对方没有提到或一笔带过的**：
  - “确诊即赔”赔的是哪些病、轻症和重症怎么分、等待期多长；
  - “3,980 元起”对应的缴费年限和保障期限；
  - “最高返还 150%”需要缴满多少年、持有多久、中途退保拿回多少；
  - 除外责任和既往症怎么处理；
  - “限时 3 天”之后的价格有没有变化。
  这些都是同类保险宣传通常会披露、并直接影响你是否划算的信息。

## 可信度与事实核查
- **综合可信度**：偏低——不是说产品有问题，而是宣传页提供的信息不足以判断。
- **关键点核查**：
  - 保额 50 万、价格 3,980 元起：未联网核查（以正式保险条款和费率表为准）
  - “最高返还 150%”：未联网核查（目前只有宣传方自己的说法，条件未说明）
  - “限时、名额有限”：未联网核查（页面没有给出截止依据）

## 给你的建议
- **我的倾向**：先别急。这页宣传不足以做决定，需要看到完整的保险条款再说。
- **结合你的情况**：如果你是第一次买重疾险的人，建议先弄清自己的保障缺口和年度预算，再比较几家产品；如果你已经有医保和一定储蓄，要问清“返还”这部分是否值得为它多花钱。是否购买请你自行判断，重要决定建议咨询持牌的保险顾问。
- **建议你再问清楚的问题**：
  1. 保障的疾病有多少种？轻症、中症、重症的赔付比例和等待期是多少？
  2. 要缴多少年？中途退保能拿回多少？“最高 150%”需要满足什么条件？
  3. 既往症、除外责任、投保年龄和健康告知有哪些限制？
```

**这个示例体现的校准点**：没有说“这是坑”；没有替用户决定买不买；“限时”只作为追问，没有定性为虚假；“可信度偏低”的理由是“信息不足”，不是“欺骗”。

# S2 消费与金融销售

**什么情况下读我**：内容是保险、理财、基金产品的说明或宣传；课程与知识付费广告；保健品、医美宣传；楼盘广告；带货种草的软文。发布者想让你**掏钱，而且尽快掏钱**。读之前应已读过通用五问手册。服务型预付年卡（宠物寄养、健身、洗护等）也归本卡：按 9c 预付式消费清单自查，并在报告里用大白话点明“这属于预付式消费，先付钱后按次核销”（不要写“按消费销售来拆”等内部术语）。

> **高风险领域**：涉及投资、医疗健康、法律时，只指出风险点和该追问的问题，评价“宣传材料本身”的可信度，**不替用户做最终决定**（不说买/不买、吃/不吃），并提示咨询持牌专业人士。核查锚点：理财与基金以**产品说明书与风险揭示书**为准，保险以正式条款与费率表为准；宣传页不是合同。

## 检查清单

| # | 检查项 | 要看什么 |
| :--- | :--- | :--- |
| 1 | **收益是保证还是演示** | “预期收益”“演示收益”“历史年化”：写的是合同保证的，还是假设的、过去的？ |
| 2 | **历史业绩的取样** | 选的是哪段区间？只给最好阶段，还是全周期？有没有同类平均作对照？ |
| 2b | **风险等级与资金投向** | 理财/基金：风险等级几级？钱投到哪里（存款、债券、股票、非标）？是否可能亏本金、历史上最差亏过多少？“稳健”不等于保本 |
| 2c | **起购门槛** | 查正式说明书：最低认购额、追加金额、资金锁定多久？这些是产品规则，不是给用户的配置建议；不推断用户有多少钱，不建议投入金额、比例、分批或分散方案 |
| 3 | **全部费用与退出代价** | 手续费、管理费、托管费、佣金、退出或退保损失、续费价格、隐含的“需要再买的东西”；封闭期多长、能否提前赎回、提前赎回的代价 |
| 4 | **免责条款与小字** | 除外责任、等待期、免赔额、赔付条件、不适用情形；医疗险还要看报销范围（是否限社保目录内、医院等级要求，如是否限二级及以上公立医院）；与在职状态绑定的团体险（如公司团体医疗险）要追问离职后本人/家属保障是否延续、怎么接续；“最终解释权归 XX 所有”类条款（见话术表） |
| 5 | **适用与不适用人群** | 谁适合？谁不适合？ |
| 6 | **紧迫感是否真实** | “限时”“限量”“最后 X 个名额”：有没有截止时间、是否反复出现、倒计时是否每次重置 |
| 7 | **是否为未标注的广告** | 种草内容是否有“广告/合作”标注；作者是否与商家有利益关系 |
| 8 | **功效与资质** | 保健品、医美的功效声明：有无批准文号或资质？有无试验证据？是否把“辅助”说成“治疗” |
| 9 | **成功案例与好评率的代表性** | “学员月入过万”“客户收益 30%”“98% 家长表示进步明显”：是个例还是普遍？多少人、怎么问的、“进步”指什么？样本是否挑选？收入截图还要问：是净收入还是流水，扣没扣成本（投流、工具、平台抽成） |
| 9b | **排名与奖项** | “同类排名前 5%”“荣获 XX 奖”：由谁排、哪一类、截至哪天、共有多少同类？如内容主体就是榜单，再读 S5 |
| 9c | **预付式消费** | 年卡、课包、储值卡：门店/机构的经营稳定性（开了几年、租约、关店转卡规则）；卡是单店用还是连锁多店通用；服务是否限次、限时段。把使用条件和办理顺序分开：「需预约」不说明是先付款还是先锁名额，也不保证已订场次能抵扣。原文没说就向门店问，不写成条款；赠送权益的兑现条件（如“买课包送 3 节课”要不要满足什么条件、送的课有没有有效期、是否限时段）；退卡转卡怎么算 |
| 9d | **商品预售与优惠兑现** | 要书面预售或活动规则：订金/定金和尾款各多少，何时付、能否退；优惠能否叠加，名额按什么计、赠品何时兑现；最迟何时发货、延误或取消怎么处理。只查材料实际涉及、足以影响决定的项 |
| 10 | **真实亮点** | 条款清晰、费用透明、风险提示完整的，要承认 |

## 常见话术与对应追问

| 话术 | 通常需要弄清的 | 可以追问 |
| :--- | :--- | :--- |
| “预期年化 6%” | 是否保证、从何而来 | “这 6% 是合同保证的吗？不达预期会怎样？” |
| “历史最高收益 35%” | 区间选择、平均水平 | “近 5 年每一年的收益分别是多少？同类平均呢？” |
| “零手续费” | 其他费用是否转移 | “管理费、赎回费、续费价格分别是多少？” |
| “限时优惠，仅剩 3 个名额” | 真实性 | “优惠截止日期是哪天？之后价格是多少？” |
| “学员平均月入过万” | 统计口径 | “这是多少学员的平均？是所有学员还是其中成功的？” |
| “纯天然，无副作用” | 证据与资质 | “有批准文号吗？有哪些试验支持？谁可以不吃？” |
| “以合同条款为准” | 关键条款是什么 | “请把免责条款和退保规则的具体页码给我看。” |
| “最终解释权归本店/本公司所有” | 发生争议时谁说了算 | 指出：真发生争议时消费者可能被动；这种写法在法律上通常站不住（惯例/常识层面）。**不下“该条款无效”的法律结论**；建议把权益落到书面，争议时咨询专业人士或 12315 |
| “历史兑付率 100%” | 过去≠未来，兑付≠保本 | “统计的是哪些产品、哪段时间？‘兑付’指保住本金还是达到基准？”明确点破：兑付率 100% 不代表未来、也不等于保本 |
| “比存银行强多了” | 对比口径不止利率一个维度 | “按什么利率比？流动性（急用钱拿不拿得出）、通胀、保障成本这几项怎么比？”不接受只比单一维度的对比 |

## 完整示例（全部虚构）

**材料**：“安康福”终身重疾险宣传页——“确诊即赔，**保额 50 万**！30 岁男性每年仅需 **3,980 元**起！累计返还，**最高可返还已交保费的 150%**！限时 3 天，名额有限！”

**分类**：M2 + S2（高风险：保险）。

```markdown
## 一句话讲人话
这页用“确诊即赔”和“最高返还 150%”推销重疾险，但没写哪种诊断算数，也没写满足什么条件才能返还。

## 事实与拆解
- **对方重点让你看的**：给出了保额（50 万）和一个特定人群起价（30 岁男性每年 3,980 元起，非人人适用），用“限时 3 天”催人决定。
- **对方没有提到或一笔带过的**：等待期、除外责任、缴费年限、返还触发条件和中途退保能拿回多少，都会直接决定这份保障实际值不值。

## 核查与可信度
保额、起价、最高返还比例均来自宣传页且未联网核查，分别以保障条款、费率表和返还条款为准；本页信息不足以判断赔付和返还条件（不代表产品一定有问题）。

## 给你的建议
先向保险方要完整条款和费率表，请对方指出：哪些诊断符合赔付条件，等待期多长？达到最高返还须缴多久，中途退保按哪张现金价值表算？再请销售方出示活动规则，确认 3 天后具体哪项权益会变。若要据此投保，带正式条款咨询持牌保险顾问。
```

**这个示例体现的校准点**：没有说“这是坑”；没有替用户决定买不买；“限时”只作为追问，没有定性为虚假；“可信度偏低”的理由是“信息不足”，不是“欺骗”。

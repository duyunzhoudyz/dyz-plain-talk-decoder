# S3 企业公关与资本市场

**什么情况下读我**：内容是财报与业绩会纪要、上市公司公告、公关声明与道歉信、裁员公开信、融资新闻、券商研报。发布者想**维持信心、淡化坏消息**。读之前应已读过通用五问手册。

> **高风险领域**：涉及投资时，只讲风险点和该追问的问题，评价“这份材料本身”如何，**不替用户做“买/卖/持有”的决定**，并提示咨询持牌专业人士。

## 检查清单

| # | 检查项 | 要看什么 |
| :--- | :--- | :--- |
| 1 | **指标口径是否一致** | 与上期、上年相比，用的是同一口径吗？有没有换成更好看的指标（如突然强调“用户数”而不提“收入”）？ |
| 2 | **同比环比的选取** | 增长是和哪个基数比的？基数是否异常低？ |
| 3 | **一次性项目** | 是否有一次性收益/损失、非经常性项目？“调整后”利润调整了什么？ |
| 4 | **委婉语对应的动作** | “战略调整”“组织优化”“聚焦核心业务”“降本增效”：实际指什么（裁员？关停？出售？）原文有没有说明规模。**遇到表里没列的新委婉语，按同样方式处理**：给“通常可能”的惯例解读＋列规模与人员影响为缺失，不断言 |
| 5 | **声明是否回应了质疑** | 回应了哪些？绕开了哪些？有没有明确的数字、时间、责任主体 |
| 6 | **道歉信的构成** | 有没有明确“错在哪”“影响了谁”“怎么补救”“何时完成” |
| 7 | **研报利益关系** | 发布机构是否与该公司有业务往来；评级用词是否有统一定义 |
| 8 | **融资新闻的金额性质** | 已到账、已签约、意向、估值；本轮金额与累计金额区分 |
| 9 | **真实亮点与坏消息的位置** | 坏消息是否写在很后面、很小；好消息是否有具体数字 |
| 10 | **坦诚之处** | 主动披露的风险、承认的问题——要承认 |

## 常见话术与对应追问

| 话术 | 通常意味着（需结合原文判断） | 可以追问 |
| :--- | :--- | :--- |
| “优化组织结构” | 可能涉及裁员或合并部门 | “涉及多少人？涉及哪些部门？补偿方案是什么？” |
| “降本增效” | 可能涉及压缩开支、人员或业务调整，也可能只是常规管理动作 | “降的是哪部分成本？涉及多少人或业务？增效有没有具体数字？” |
| “聚焦核心业务” | 可能收缩或关停部分业务 | “哪些业务被缩减？是否有时间表？” |
| “调整后利润” | 剔除了一些项目 | “调整了哪些项目？为什么这些项目不算？” |
| “用户规模突破 X 亿” | 可能是注册用户而非活跃用户 | “是月活还是累计注册？” |
| “完成 A 轮亿元融资” | 金额可能是意向 | “钱是否已到账？投资方是谁？估值多少？” |
| “对由此造成的不便深表歉意” | 可能没有承认具体问题 | “具体问题是什么？谁来负责？怎么补救？” |

## 完整示例（全部虚构）

**材料**：“青禾云科技”季度业绩新闻稿——“本季度公司营收同比增长 28%，用户规模突破 3,000 万，持续优化组织结构，聚焦核心业务，调整后净利润实现扭亏为盈。”（原文未给出具体财务表，也没有上季度同口径数据。）

**分类**：M2 + S3（高风险：投资相关）。

```markdown
## 一句话讲人话
青禾云说这个季度收入涨了 28%、用户过了 3,000 万、调整后扭亏为盈。这几个说法都是好消息，但这篇稿子没给完整财务数据，“调整后”调整了什么、“用户”指什么，现在无法判断。

## 核心事实（去水版）
- **营收**：同比增长 28%（没给具体金额和上年基数）。
- **用户**：规模“突破 3,000 万”（没说是月活还是累计）。
- **利润**：“调整后净利润”扭亏为盈（没说调整了哪些项目、未调整的数字）。
- **组织**：称“持续优化组织结构，聚焦核心业务”，没有给出规模。

## 滤镜拆解 / 潜台词
- **对方重点让你看的**：营收增长、用户规模、扭亏。
- **对方没有提到或一笔带过的**：
  - 营收的具体金额，以及 28% 的比较基数；
  - 3,000 万用户的口径（月活/累计注册）；
  - “调整后净利润”调整了什么，按通用会计口径的净利润是多少；
  - “优化组织结构”涉及的人数和部门。
  对于业绩稿，这些通常会在附带的财务表或公告中出现——如果完整财报里有，以财报为准。
- **关于“组织优化”**：这类表述通常可能意味着人员或部门调整，但原文没有说明，**不能断定是裁员**。

## 可信度与事实核查
- **综合可信度**：中（数字没有矛盾，但材料不完整）
- **关键点核查**：
  - 营收同比 +28%：未联网核查（建议对照正式财报）
  - 用户规模 3,000 万：未联网核查（口径不明）
  - 调整后净利润扭亏：未联网核查（调整项不明）

## 给你的建议
- **我的倾向**：先别急着下结论。这篇稿子能说明“公司想让你看到的是增长和扭亏”，但不足以判断经营是否真的好转。
- **结合你的情况**：如果你持有或关注这家公司，建议先看完整财报和公告中的财务表；如果只是看新闻，不用管。涉及投资决定，请咨询持牌专业人士，这里不对买卖给出意见。
- **建议你再问清楚的问题**：
  1. 按通用会计口径（不调整）的净利润是多少？“调整”扣除了哪些项目？
  2. 3,000 万用户是月活还是累计注册？和上一季度同口径相比如何？
  3. 营收增长来自主营业务，还是一次性收入或并表？
```

**这个示例体现的校准点**：“优化组织结构”只写“可能”，没有断言裁员；没有说“财报造假”“数据注水”，因为没有任何证据；没有给买卖建议；承认好消息本身是原文明确的内容。

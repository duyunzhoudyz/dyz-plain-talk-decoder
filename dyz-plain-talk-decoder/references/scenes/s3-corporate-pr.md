# S3 企业公关与资本市场

**什么情况下读我**：内容是财报与业绩会纪要、上市公司公告、公关声明与道歉信、裁员公开信、融资新闻、券商研报。发布者想**维持信心、淡化坏消息**。读之前应已读过通用五问手册。

> **高风险领域**：涉及投资时，只讲风险点和该追问的问题，评价“这份材料本身”如何，**不替用户做“买/卖/持有”的决定**，并提示咨询持牌专业人士。

## 检查清单（后台自查雷达：只挑真正影响当下判断的 2–3 个关键缺口写进报告，不整表倒给读者）

| # | 检查项 | 要看什么 |
| :--- | :--- | :--- |
| 1 | **指标口径是否一致** | 与上期、上年相比，用的是同一口径吗？有没有换成更好看的指标（如突然强调“用户数”而不提“收入”）？ |
| 1b | **签约/意向额与确认收入** | **明确区分：新签合同额、意向额、在手订单额 ≠ 当期已确认的营业收入或已到账现金**；签约增长幅度不能直接等同于营收或利润变好，要看履约进度、收入确认周期与回款情况 |
| 2 | **同比环比的选取** | 增长是和哪个基数比的？基数是否异常低？ |
| 3 | **一次性项目与配对费用** | 是否有一次性收益/损失、非经常性项目？“调整后”利润调整了什么？**注意一次性收益背后是否伴随对应费用（如搬迁、处置、补偿相关支出），以及当期是否还有其他未列明的一次性收支项**——仅用净利润减去单项一次性收益不能直接叫成“完整主营业务利润”，须索取财务附注核对 |
| 4 | **委婉语对应的动作** | “战略调整”“组织优化”“聚焦核心业务”“降本增效”：实际指什么（裁员？关停？出售？）原文有没有说明规模。**遇到表里没列的新委婉语，按同样方式处理**：给“通常可能”的惯例解读＋列规模与人员影响为缺失，不断言 |
| 5 | **声明是否回应了质疑** | 回应了哪些？绕开了哪些？有没有明确的数字、时间、责任主体 |
| 6 | **道歉信的构成** | 有没有明确“错在哪”“影响了谁”“怎么补救”“何时完成” |
| 7 | **研报利益关系** | 发布机构是否与该公司有业务往来；评级用词是否有统一定义 |
| 8 | **融资新闻的金额性质** | 已到账、已签约、意向、估值；本轮金额与累计金额区分 |
| 9 | **真实亮点与坏消息的位置** | 坏消息是否写在很后面、很小；好消息是否有具体数字 |
| 10 | **坦诚之处** | 主动披露的风险、承认的问题——要承认 |

## 常见话术与对应追问

| 话术 | 通常意味着（需结合原文判断） | 可以追问 |
| :--- | :--- | :--- |
| “优化组织结构” | 可能涉及裁员或合并部门 | “涉及多少人？涉及哪些部门？补偿方案是什么？” |
| “降本增效” | 可能涉及压缩开支、人员或业务调整，也可能只是常规管理动作 | “降的是哪部分成本？涉及多少人或业务？增效有没有具体数字？” |
| “聚焦核心业务” | 可能收缩或关停部分业务 | “哪些业务被缩减？是否有时间表？” |
| “调整后利润” | 剔除了一些项目 | “调整了哪些项目？为什么这些项目不算？一次性收益有没有对应的配对费用？” |
| “新签订单/签约额增长 X%” | 签约/意向不等于已确认收入 | “这笔签约什么时候确认收入？回款节奏和履约条件是什么？” |
| “用户规模突破 X 亿” | 可能是注册用户而非活跃用户 | “是月活还是累计注册？” |
| “完成 A 轮亿元融资” | 金额可能是意向 | “钱是否已到账？投资方是谁？估值多少？” |
| “对由此造成的不便深表歉意” | 可能没有承认具体问题 | “具体问题是什么？谁来负责？怎么补救？” |

## 完整示例（全部虚构）

**材料**：“青禾云科技”季度业绩新闻稿——“本季度公司营收同比增长 28%，用户规模突破 3,000 万，持续优化组织结构，聚焦核心业务，调整后净利润实现扭亏为盈。”（原文未给出具体财务表，也没有上季度同口径数据。）

**分类**：M2 + S3（高风险：投资相关）。

**输出（标准版，平实语气，离线自然段直答）**

> 单看这份青禾云季度业绩新闻稿，虽然报了营收增长 28%、用户破 3,000 万和调整后净利润扭亏，但没附正式财务表，判断不了公司按通用会计口径到底赚没赚钱。
>
> 营收同比涨 28% 和调整后利润转正是原文给出的正面进展，但缺了上年同期基数，看不出增长含金量；“用户规模 3,000 万”也没说明是月活还是累计注册；“调整后净利润”不等于报表净利润，稿里没列剔除了哪些一次性或非经常项目，也没说背后有没有配对费用。另外，“优化组织结构”“聚焦核心业务”在业绩稿里通常可能涉及人员或业务收缩，但原文没提部门和人数，不能直接断言在裁员。
>
> 如果你关注它的经营，下一步直接去翻正式财报的利润表和附注：核对报表净利润、调整明细里一次性项目占多少及有无对应费用，以及同口径活跃用户相对上季的变化。单凭新闻稿不足以做投资判断，重要决定请咨询持牌专业人士。

**这个示例体现的校准点**：“优化组织结构”只写“可能”，没有断言裁员；没有说“财报造假”“数据注水”，因为没有任何证据；没有给买卖建议；承认正面进展本身是原文明确的内容；短新闻稿自然段一次说清，不硬套表单壳或评级标签。

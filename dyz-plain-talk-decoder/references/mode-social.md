# M5 社媒热点降噪

**什么情况下读我**：内容是微博热搜、X 讨论串、情绪化短视频、转发刷屏的帖子——**信息碎、情绪浓、站队多**。目标是剥掉情绪和立场，还原“发生了什么、各方怎么说、哪些已被证实”。

## 一、三个动作

### 1. 按时间线还原

把事件按时间顺序排好，每个节点标注**来源**和**时间**（有则标，没有写“时间不明”）。

```text
[时间/不明] 谁，做了什么/说了什么（来源：……）
```

### 2. 各方说法分开写

不要把不同当事方的话混在一起。每一方单独列，各写各的。**不替任何一方站队**。

### 3. 三分法

把所有信息归入三类，并**明确标出**：

| 类别 | 含义 | 标注 |
| :--- | :--- | :--- |
| **已证实的事实** | 已读可靠正文或原始证据，直接支持该项具体事实；转载同一通报不算独立印证 | `[已核实]` |
| **单方说法** | 只有某一方（当事人、爆料者、相关公司）这样说，没有第三方印证 | `[未证实/单方说法]` |
| **情绪与立场表达** | 评论、感叹、站队、猜测、阴谋论 | 不当作事实，说明“属于观点” |

核查细则、三态标注、不能联网时的写法，见 `SKILL.md` 路由表指向的核查手册。这里只强调三点：① 没联网时，“已证实的事实”一栏改名为“帖子里可见的事实（未联网核查）”，只转述你看到的内容，不打 `[已核实]`；② 当事方的表态（如“正在核实”）只是表态，不是待核查的事实声明，不必打三态标签，写“尚未公布结果”即可；③ 没联网时“单方说法”一栏同样不打三态标签，平实写“某方称……（没有第三方印证）”。联网核查过之后，**标注固定为 `[已核实]`、`[存疑/有出入]`、`[未证实/单方说法]`**。

## 二、“截至目前”的写法

事件仍在发展时：

- 开头写：“**截至目前**……”，并说明截至什么时候：能看到发布时间就写发布时间；只有用户粘贴的文字、看不到时间时，写“截至你给我这份内容时”；
- 结尾写：“后续可能有新的通报或证据，以上结论可能变化”；
- **不提前下定论**，不用“真相是”“反转了”这类词；
- 当事方还没回应的，写“XX 方尚未公开回应”，**不要推测对方为什么不回应**。

## 三、常见陷阱

| 陷阱 | 怎么处理 |
| :--- | :--- |
| 营销号“据说”“网传”“有内部人士透露” | 归入单方说法或未证实，不当事实 |
| 只看到视频片段 | 说明“只看到片段，前后情况不明”。**“是否剪辑”本身是某一方主张时**（如门店称“剪辑误导”），把该主张归入单方说法；事实栏不写“剪辑过”，只写“只看到片段” |
| 带情绪标题（“令人愤怒！”） | 去掉标题里的情绪词，只保留可证实的信息 |
| 评论区大量站队 | 不把评论区的“多数人认为”当事实；可写“评论区情绪偏……”作为一句背景 |
| 评论区里的证据性质疑（如指出照片是旧图） | 不与情绪站队混为一谈：按“单方观察、未核实”列出，并把对应疑点写进“目前不清楚的”清单 |
| 旧闻翻炒（旧图、旧事伪装成新事） | 尽可能核对发布时间；发现疑似旧事就说明 |
| 阴谋论或动机猜测 | 不写。除非有公开证据，否则只写“动机不明” |

## 四、输出

按标准模板，“滤镜拆解 / 潜台词”换成“**时间线 + 三分**”：

```markdown
## 时间线与三分
**时间线（截至目前）**
- [时间] ……（来源）
- [时间] ……（来源）

**已证实的事实**
- ……`[已核实]`

**单方说法**
- 甲方称：……`[未证实/单方说法]`
- 乙方称：……`[未证实/单方说法]`

**情绪与立场（不当作事实）**
- 评论区主要有“……”“……”两种情绪。

**目前不清楚的**
- ……
```

（模板里的三态只用于已联网核查的子声明；离线用上文第二节的离线栏名和写法，不打三态。）“目前不清楚的”必须**明列核心争议事实本身**（如“是否雇托”“原料是否过期”），不能只列周边细节而把核心争议藏在别的句子里。涉事各方身份的真伪（如“自称前员工”是否属实；聊天截图里对话双方的备注身份也算——备注可以任意设置，不代表真实职务）、关键物证的时间与语境（照片何时拍、视频是否完整）也应列入这份清单，不要只写在单方说法的括注里。

“给你的建议”：多数情况下是“这事和你无关，不用着急站队”或“等官方进一步通报再看”，除非事件对用户有直接影响（如涉及食品安全召回）。事件与用户消费决策相关时，再给一个**不站队、可操作的观察方法**（如“在意这家店的话，可以对比开业期与常态期的排队差异再判断”），而不是只说“等通报”。涉及商家经营传闻（跑路、欠薪）时，独立核实出口可给：企业信用信息公示系统（经营异常、行政处罚）、监管或警方通报、实地观察；只向当事方要说法不算独立核实。

## 五、示例（虚构）

**材料**：微博上刷屏的帖子——“某‘奶茶屋’门店被曝使用过期原料！网友愤怒！视频为证！”帖子附一段 8 秒视频：后厨一名人员把一包原料倒入桶中，包装上日期看不清。品牌方官方账号随后发布一句话声明：“已关注，正在核实。”评论区大量情绪化留言。

```markdown
## 一句话讲人话
网上有人发了一段视频，说某奶茶店用过期原料；品牌方只回应了“正在核实”。目前没有证据能确认原料是不是过期，也没有官方调查结果。

## 核心事实（去水版）
- 有一段 8 秒视频，显示后厨人员倒原料；视频里看不清包装日期。
- 品牌方回应“已关注，正在核实”。
- 目前没有看到监管部门通报。

## 时间线与三分
**时间线（截至目前）**
- [发布时间不明] 爆料帖发布，附 8 秒视频（来源：该帖）。
- [之后] 品牌方官方账号回应“已关注，正在核实”（来源：官方账号）。

**帖子里可见的事实（未联网核查）**
- 帖子附有视频，内容为后厨倒入原料；品牌方发表了回应声明。

**单方说法**
- 爆料者称：原料已过期（视频中看不清日期，没有第三方印证）。
- 品牌方表态：正在核实（尚未公布结果）。

**情绪与立场（不当作事实）**
- 评论区主要是愤怒与要求严查的情绪，这些是观点，不是证据。

**目前不清楚的**
- 视频拍摄的时间、地点是否就是该门店；
- 原料是否真的过期；
- 监管部门是否已介入。

## 可信度与事实核查
- **综合可信度**：偏低——仅按帖子判断，日期看不清，核心指称没有得到材料支持；未联网核查，不是断言指称为假。

## 给你的建议
- **我的倾向**：先别急着下结论，等官方通报。
- **结合你的情况**：如果你经常去这家店，可以等监管通报后再决定；平时不吃，就不用管。
- 本次内容截至获取时间，后续可能有新通报，结论可能变化。
```

**这个示例体现的校准点**：不替任何一方站队；“品牌方没给细节”只写“正在核实”，不推测其动机；区分“视频存在”和“视频证明了什么”；没联网时不打 `[已核实]`。

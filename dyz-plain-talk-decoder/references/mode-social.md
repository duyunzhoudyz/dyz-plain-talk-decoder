# M5 社媒热点降噪

**什么情况下读我**：内容是微博热搜、X 讨论串、情绪化短视频、转发刷屏的帖子——**信息碎、情绪浓、站队多**。目标是剥掉情绪和立场，还原“发生了什么、各方怎么说、哪些已被证实”。

## 一、三个动作

### 1. 按时间线还原

把事件按时间顺序排好，每个节点标注**来源**和**时间**（有则标，没有写“时间不明”）。

```text
[时间/不明] 谁，做了什么/说了什么（来源：……）
```

### 2. 各方说法分开写

不要把不同当事方的话混在一起。每一方单独列，各写各的。**不替任何一方站队**。

### 3. 三分法

把所有信息归入三类，并**明确标出**：

| 类别 | 含义 | 标注 |
| :--- | :--- | :--- |
| **已证实的事实** | 已读可靠正文或原始证据，直接支持该项具体事实；转载同一通报不算独立印证 | `[已核实]` |
| **单方说法** | 只有某一方（当事人、爆料者、相关公司）这样说，没有第三方印证 | `[未证实/单方说法]` |
| **情绪与立场表达** | 评论、感叹、站队、猜测、阴谋论 | 不当作事实，说明“属于观点” |

核查细则、三态标注、不能联网时的写法，见 `SKILL.md` 路由表指向的核查手册。这里只强调三点：① 没联网时，只客观转述“帖子里直接可见的内容”，不打 `[已核实]`，也不必逐条刷屏挂“未联网核查”；② 当事方的表态（如“正在核实”）只是表态，不是待核查的事实声明，不必打三态标签，写“尚未公布结果”即可；③ 没联网时单方说法同样不打三态标签，平实写“某方称……（目前没有第三方印证）”。联网核查过之后，**标注固定为 `[已核实]`、`[存疑/有出入]`、`[未证实/单方说法]`**。

## 二、“截至目前”的写法

事件仍在发展时：

- 开头写：“**截至目前**……”，并说明截至什么时候：能看到发布时间就写发布时间；只有用户粘贴的文字、看不到时间时，写“截至你给我这份内容时”；
- 结尾写：“后续可能有新的通报或证据，以上结论可能变化”；
- **不提前下定论**，不用“真相是”“反转了”这类词；
- 当事方还没回应的，写“XX 方尚未公开回应”，**不要推测对方为什么不回应**。

## 三、常见陷阱

| 陷阱 | 怎么处理 |
| :--- | :--- |
| 营销号“据说”“网传”“有内部人士透露” | 归入单方说法或未证实，不当事实 |
| 只看到视频片段 | 说明“只看到片段，前后情况不明”。**“是否剪辑”本身是某一方主张时**（如门店称“剪辑误导”），把该主张归入单方说法；事实栏不写“剪辑过”，只写“只看到片段” |
| 带情绪标题（“令人愤怒！”） | 去掉标题里的情绪词，只保留可证实的信息 |
| 评论区大量站队 | 不把评论区的“多数人认为”当事实；可写“评论区情绪偏……”作为一句背景 |
| 评论区里的证据性质疑（如指出照片是旧图） | 不与情绪站队混为一谈：按“单方观察、未核实”列出，并把对应疑点写进“目前不清楚的”清单 |
| 旧闻翻炒（旧图、旧事伪装成新事） | 尽可能核对发布时间；发现疑似旧事就说明 |
| 阴谋论或动机猜测 | 不写。除非有公开证据，否则只写“动机不明” |

## 四、输出组织（统一遵循 `SKILL.md` 第 9 步输出手册）

不论长短，必须守住核心约束：**说清截至什么时候、当事方各自说法分开、事实/单方说法/情绪清晰区分、明列核心争议本身与未核实点、不提前站队**。

- **短热搜帖 / 单条争议帖**：不必硬拆 5 个加粗子块或套 4 个 `##` 大标题——用 2–3 个自然段把“截至所贴内容发生了什么、哪句能证到哪、哪句只是单方说法或评论区情绪、核心没查清的是什么、能怎么观察或核实”一次讲透，“截至所贴内容”说一次即可，离线不硬贴“综合可信度偏低”标签；
- **多方来回反转、时间跨度长的热点**：再用精简 `##` 小节与时间线分层方便扫读（联网核查过的声明才打三态，离线不打三态）。

**必须明列核心不清楚项**：核心争议事实本身（如“是否雇托”“原料是否过期”）必须直接点明，不要藏在括注里。涉事各方身份真伪（如“自称前员工”或聊天截图里的备注身份——备注可任意改，不代表真实职务）、关键物证的时间与语境（照片何时拍、视频是否完整）也应明确归入待核实点。

“给你的建议”：多数情况下是“这事和你无关，不用着急站队”或“等官方进一步通报再看”，除非事件对用户有直接影响（如涉及食品安全召回）。事件与用户消费决策相关时，再给一个**不站队、可操作的观察方法**（如“在意这家店的话，可以对比开业期与常态期的排队差异再判断”），而不是只说“等通报”。涉及商家经营传闻（跑路、欠薪）时，独立核实出口可给：企业信用信息公示系统（经营异常、行政处罚）、监管或警方通报、实地观察；只向当事方要说法不算独立核实。

## 五、示例（虚构，自然段直给正例）

**材料**：微博上刷屏的帖子——“某‘奶茶屋’门店被曝使用过期原料！网友愤怒！视频为证！”帖子附一段 8 秒视频：后厨一名人员把一包原料倒入桶中，包装上日期看不清。品牌方官方账号随后发布一句话声明：“已关注，正在核实。”评论区大量情绪化留言。

**输出（标准版，平实语气，离线自然段直答）**

> 截至你贴的这条帖子，目前没法确认这家“奶茶屋”到底用没用过期原料，先别急着站队——网传的 8 秒视频看不清包装日期，品牌方也只回了“正在核实”，还没有监管调查结果。
>
> 帖子里能直接看到的事实只有两件：附带的一段 8 秒视频拍到后厨有人把一包原料倒进桶里，但日期模糊看不清；品牌官方账号随后发了一句“已关注，正在核实”。“原料已过期”目前只是爆料者的单方说法，评论区里大量愤怒和要求严查的留言属于情绪表态，都不算证据；品牌方暂未给细节也不能直接推成回避或默认。最核心的几件事都还没查清：视频拍摄的时间和地点是不是这家门店、原料本身到底过没过期，以及监管部门有没有介入。
>
> 以上只按你贴的帖子看，没查外部通报，后续有新证据结论可能变化。如果你常去这家店，先等市场监管部门或品牌公布带凭证的核查结果再决定；平时不去，不用跟着情绪跑。

**这个示例体现的校准点**：不替任何一方站队；“品牌方没给细节”不推测动机；区分“视频存在”和“视频证明了什么”；核心争议与物证语境明确写出；离线不打三态、不硬拆 5 个子块也不硬贴“综合可信度偏低”标签。

# 人话解码器（dyz-plain-talk-decoder）

把文章、帖子、通稿、视频链接变成**人话**：到底讲了什么、写的人想让你做什么、哪些靠谱哪些存疑、这事跟你本人有什么关系。

**当前范围：中文文本 Beta 候选版。** 把技能目录装进支持 Skill 的助手，直接贴文字即可，不需要 Python 或 API Key。链接、字幕、转写、画面都是可选增强；没拿到原材料时，请改贴原文或截图。这个版本不承诺任意链接可读，也不代替专业核查。

## 这是什么

你贴一篇公众号文章、一条热搜、一份保险广告、一个 B 站链接，说“讲人话”或“帮我脱水”，它会：

- **说清事实**：去掉形容词和套话，留下数字、日期、条件；
- **拆掉包装**：对方重点让你看什么、没提什么（“没提”不等于“隐瞒”，每条判断都要有证据）；
- **标注可信度**：能联网就核查关键说法并附来源，不能联网就如实标“未联网核查”，绝不假装查过；
- **给你建议**：结合你自己的情况（可选的本地画像），指出该追问的问题。

它**不是**普通摘要，也**不是**挑刺机器：内容扎实就直说“基本实在”，例行通稿就说“没有明显新信号”。医疗、投资、法律这类高风险领域，它只指出风险点和该问的问题，**不替你做最终决定**。

## 能做什么

| 能力 | 说明 | 需要安装吗 |
| :--- | :--- | :--- |
| 文字解码 | 粘贴的文章、帖子、通稿、JD、财报、合同（通用框架＋“不是法律意见”提示） | 不需要 |
| 截图解码 | 助手有视觉能力时，读图里的文字再解码 | 不需要 |
| 图文链接抓取 | 普通网页、公众号，可从分享口令找链接；社媒公开摘要不当全文 | 脚本需基础层；助手能直接读网页也可不装 |
| 视频与本地音视频解码 | 链接先取可用字幕，无字幕再走已配置的转写；本机 `.mp3/.m4a/.wav/.mp4` 等文件可直接传给脚本转写（跳过下载），有逐字稿且需看画面时再抽帧 | 链接需基础层+视频依赖；本地音视频只需 `ffmpeg` + ASR |
| 小宇宙播客单集 | 读取公开单集标题、节目名、Shownotes 与公开音频线索，最多返回 `partial`，绝不把简介冒充整期逐字稿 | 脚本需基础层 |
| 联网核查 | 找到网址只是线索；实际读到来源正文且支持具体说法，才标该说法已核实。摘要、同源转载、局部支持不为整句话背书 | 需助手能访问来源正文；离线则注明未联网核查 |
| 分享卡片导出（可选） | 用户说“生成分享页/发朋友”时，用纯标准库脚本把解码报告转成离线单页 HTML，支持“只看存疑与避坑”筛选与打印存 PDF | 仅需 Python 3.10+（零第三方依赖） |
| 个人画像 | 可只说当次情况或跳过。只有确认是用户设备上的私人目录且获同意，才保存在本机 | 不需要；云端、共享或归属不明只在本次对话使用 |

五种内容各有专门手册：官方通稿（M1）、利益方话术（M2，含产品发布/消费金融/企业公关/招聘/研究数据五张场景卡）、AI 洗稿排雷（M3）、深度脱水（M4）、社媒热点降噪（M5）。助手会自动分类，你不用管。

先看效果？查看[**公开样板间（examples/）**](examples/README.md)——包括用本技能**不护短地自查本仓库自己的 `README.md`**（附[单页 HTML 分享卡](examples/01-self-audit-readme.html)），以及促销混合稿、理财高风险边界、官方公报极速版和“不尬黑”干净样本。

详略三档：默认标准版（300–600 字）；说“极速版/三句话总结”更短；说“深度拆解”更详细。语气两档：默认平实直白；说“毒舌点/犀利点”换吐槽版（只改措辞，不改事实和结论）。

## 安装

### 第一步：把技能放进你的 AI 助手

只需要仓库里的 `dyz-plain-talk-decoder/` 这个目录（其余是开发、CI、插件清单和测试文件，不用管）。不同宿主按下面任选一种方式安装：

| 宿主 / 环境 | 安装方式 | 可用能力档位 |
| :--- | :--- | :--- |
| **Claude Code（推荐插件方式）** | 仓库根目录已提供 `.claude-plugin/marketplace.json` 与 `plugin.json`，发布到 GitHub 后可按 `/plugin marketplace add <owner>/<repo>` → `/plugin install dyz-plain-talk-decoder@dyz-plain-talk-decoder` 安装；本地手动安装可直接把 `dyz-plain-talk-decoder/` 复制到 `~/.claude/skills/`（全局）或项目 `.claude/skills/` | A 档（全能力） |
| **Cursor / Codex / Windsurf / WorkBuddy 等本地助手** | 将 `dyz-plain-talk-decoder/` 复制到对应助手的技能目录（如 `~/.agents/skills/`、`~/.claude/skills/` 或项目 `.cursor/skills/`）；发布到 GitHub 后也支持 `npx skills add <owner>/<repo>` 自动发现 | A 档（全能力） |
| **Qoder / 对话版 Claude 等支持导入 zip 的助手** | 把 `dyz-plain-talk-decoder/` 目录打包为 zip，在助手的技能设置里导入 | B/C 档（无本地脚本时自动降级，粘贴正文照常使用） |
| **任意纯对话助手（无技能机制）** | 直接粘贴正文并附上 `SKILL.md` 与对应 `references/` 规则即可 | B/C 档 |

- 装好后对助手说“讲人话，帮我看看这篇……”试试。助手认不出技能时，检查目录里是否有 `SKILL.md`、目录名是否完整。

### 第二步（可选）：开启链接抓取

只贴文字的话，这一步可以完全跳过。想让助手直接读链接，以下两种方式二选一：

**方式 A：用 `uv` 零配置免虚拟环境（推荐，不用手动 `pip install`）**

1. 安装 [uv](https://docs.astral.sh/uv/getting-started/installation/)；
2. 三个入口脚本均已内置 PEP 723 依赖声明，直接运行即可自动按需解析基础依赖：

   ```bash
   cd dyz-plain-talk-decoder
   uv run scripts/check_env.py
   uv run scripts/fetch_content.py "https://example.com/article"
   ```

   （视频字幕可临时追加 `uv run --with yt-dlp scripts/fetch_content.py "<视频链接>"`。）

**方式 B：传统 Python + pip**

1. 安装 [Python 3.10 或更新版本](https://www.python.org/downloads/)（Windows 安装时勾选 “Add to PATH”）；
2. 在技能目录下安装基础依赖：

   ```bash
   cd dyz-plain-talk-decoder
   python -m pip install -r requirements.txt
   ```

3. 自检一下（只检查本机配置与依赖，不验证云端账号、额度或实际识别效果）：

   ```bash
   python scripts/check_env.py
   ```

视频和语音转文字是额外的可选能力，见下一节。

## 怎么用

直接对助手说：

- “讲人话，这个通稿到底啥意思？（粘贴全文）”
- “太长不看，帮我脱水一下这篇：（粘贴或给链接）”
- “这个保险广告靠谱吗？（粘贴宣传页）”
- “这份 JD 到底想招什么人？”
- “这个热搜到底怎么回事，别让我被带节奏。（粘贴多条帖子）”
- “拆解一下这个视频讲了什么：（B站/YouTube 链接）”
- “查看我的画像。” / “建立画像。” / “更新我的画像：我换工作了。” / “删除我的画像。”

链接打不开时，助手会直说原因并请你粘贴正文——**粘贴永远是最可靠的路**。只拿到部分内容时，它会说明读到了哪里，不会假装读过全文。

## 可选能力的开启方法

所有可选依赖都在 `requirements-optional.txt` 里，按需安装，不装不影响文字解码。

### 视频字幕与音频（L0/L1/L2 的基础）

```bash
python -m pip install "yt-dlp>=2025.1"
```

再装系统级 **ffmpeg**（含 ffprobe）：

- Windows：`winget install ffmpeg`
- macOS：`brew install ffmpeg`
- Linux：用发行版包管理器，如 `sudo apt install ffmpeg`

只有能取得质量合格的软字幕轨，才能停在字幕层；视频画面上的硬字幕不等于可下载字幕。若提示 yt-dlp 过旧，可手动升级：`python -m pip install -U yt-dlp`。

### 语音转文字（ASR）：视频没有字幕时

两种方式二选一，通过**环境变量**配置（密钥只放环境变量，不要写进任何文件）：

**方式一：云端 ASR（音频发送给所选服务商，可能产生费用）**

```bash
python -m pip install "openai>=1.52"
```

设置环境变量（Windows 用“设置 → 系统 → 关于 → 高级系统设置 → 环境变量”，macOS/Linux 写进 shell 配置）：

| 变量 | 填什么 |
| :--- | :--- |
| `ASR_PROVIDER` | `openai_compatible` |
| `ASR_API_KEY` | 你的接口密钥 |
| `ASR_BASE_URL` | 服务地址。OpenAI 官方可不填；Groq 填 `https://api.groq.com/openai/v1`；阿里云百炼填业务空间专属域名 `https://{你的空间ID}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` |
| `ASR_MODEL` | 模型名。百炼填 `qwen-audio-3.0-asr-flash`（自动走原生协议，带句级时间戳）或 `qwen3-asr-flash`（兼容接口）；其他服务填对应模型 |

注意：云端接口按时长计费。超过 30 分钟的视频，助手会先告诉你预计耗时并征求同意；也可以只转写某一段（对助手说“只看 10:00 到 20:00 那段”）。

**方式二：本地 ASR（离线、免费、较慢）**

```bash
python -m pip install "faster-whisper>=1.0"
```

环境变量：`ASR_PROVIDER=local_whisper`。首次使用会下载模型；有 NVIDIA 显卡会自动用 GPU，没有则用 CPU。

### 画面抽帧（L3）

在已取得字幕或转写、有视频依赖且助手能看图时，才按需要抽取 PPT 等画面。没有可用逐字稿的纯画面或硬字幕视频，请直接发关键截图；只解释可见页，不作全片结论。只转写了一部分，即使抽到画面也仍是部分材料。

## 哪些环境实际验过

- **Windows**：历史记录在同一台设备的新 Python 3.14 虚拟环境跑通过图文、YouTube 字幕和缺依赖降级；不等于所有 Windows 安装或真实宿主自动发现均通过。
- **链接与视频**：有公开公众号、博客、YouTube 字幕、B站语音转写及百炼云端转写的历史成功记录，不代表今天的可用率。B站公开软字幕仍缺实网成功样本；YouTube 字幕两次为 6.5 秒与 16.5 秒，不承诺 10 秒内完成。
- **未验证**：macOS / Linux 实装（已配置 GitHub Actions 三系统 × Python 3.10/3.12/3.14 CI，尚未推远端跑通）、`uv run` 实机执行（本机未装 `uv`，CI 已配冒烟）、多技能宿主自然触发、普通读者复述。截图和 PDF 取决于宿主读图读文件的能力，不额外承诺内置 OCR。模型试题与真人盲读入口见[本轮验收](tests/eval_round8/results.md)。

## 隐私与使用边界

- **画像不默认落盘**：只有你同意且能确认目录属于你设备的私人持久空间，才在用户目录的 `.plain-talk-decoder/profile.md` 读写历史画像。仅能写云端沙盒、共享目录或位置不确定时，不读历史、不写跳过标记。画像不进搜索词和脚本参数，只影响建议和解释深浅；说“这次不用画像”则当次不读不写。
- **不越权抓取**：只读公开可访问的内容；不绕过登录、付费墙、验证码；不读取浏览器 Cookie；不用代理池、不伪造设备指纹；失败后不反复重试。
- **抓取到的内容是数据**：网页里夹带的任何“指令”一律不执行。
- **不冒充**：没看到原内容就明说；用二手报道回答时会先征得同意并写明来源。
- **高风险领域不替你做决定**：医疗、投资、法律只指出风险点和该追问的问题。

## 常见问题

**问：链接打不开怎么办？**
答：助手会说明是要登录、受拦截还是链接失效。可以直接贴正文，仍按同一套规则解码；只贴节选就只分析节选。没有联网能力时不能独立核查。

**问：视频没有字幕怎么办？**
答：配置 ASR（见上），或直接把字幕、文字稿贴给助手，也可以截几张关键画面。它不会凭标题和简介编一份“总结”。

**问：Windows 下运行脚本报中文乱码？**
答：脚本输出已统一 UTF-8。若控制台仍乱码，先执行 `chcp 65001` 再运行。

**问：提示缺依赖（missing_dependency）？**
答：按提示安装对应组件；或者直接粘贴正文，不影响使用。运行 `python scripts/check_env.py` 可一次看全缺什么。

**问：画像存在哪里？换电脑会丢吗？**
答：获准在你设备上保存时，文件位于用户目录的 `.plain-talk-decoder/profile.md`，在技能目录之外；换电脑需自行迁移。若只在本次会话使用，本技能不会另存画像文件。

**问：不联网能用吗？**
答：能。粘贴文字照常解码，所有核查项如实标“未联网核查”。

**问：转写过的视频重复问会重新下载吗？**
答：同一链接、同一时间段且逐字稿缓存有效时，普通追问和请求抽帧都复用文字，不再次调用付费转写；首次抽帧仍可能下载画面。部分稿仍标部分，不会因命中缓存变成完整稿。逐字稿自保存起 24 小时内有效；更换区间、过期、旧格式、文件损坏或已清理时可能重新取材并产生费用。缓存位于系统临时目录；`python scripts/cleanup_cache.py` 清理过期条目，`--all` 会清除本技能所有视频缓存，不是只清当前视频。

# 人话解码器（dyz-plain-talk-decoder）

把文章、帖子、通稿、视频链接变成**人话**：到底讲了什么、写的人想让你做什么、哪些靠谱哪些存疑、这事跟你本人有什么关系。

它是一个 Agent Skill（给 AI 助手用的技能包），装进支持 Skill 的 AI 助手里即可使用。**不装任何额外东西也能用**——把文字直接贴给助手就行。

## 这是什么

你贴一篇公众号文章、一条热搜、一份保险广告、一个 B 站链接，说“讲人话”或“帮我脱水”，它会：

- **说清事实**：去掉形容词和套话，留下数字、日期、条件；
- **拆掉包装**：对方重点让你看什么、没提什么（“没提”不等于“隐瞒”，每条判断都要有证据）；
- **标注可信度**：能联网就核查关键说法并附来源，不能联网就如实标“未联网核查”，绝不假装查过；
- **给你建议**：结合你自己的情况（可选的本地画像），指出该追问的问题。

它**不是**普通摘要，也**不是**挑刺机器：内容扎实就直说“基本实在”，例行通稿就说“没有明显新信号”。医疗、投资、法律这类高风险领域，它只指出风险点和该问的问题，**不替你做最终决定**。

## 能做什么

| 能力 | 说明 | 需要安装吗 |
| :--- | :--- | :--- |
| 文字解码 | 粘贴的文章、帖子、通稿、JD、财报、合同（通用框架＋“不是法律意见”提示） | 不需要 |
| 截图解码 | 助手有视觉能力时，读图里的文字再解码 | 不需要 |
| 链接抓取 | 普通网页、公众号、B站、YouTube 等，自动从分享口令里找链接、解析短链 | 基础层（见下） |
| 视频解码 | 省流漏斗：先拿字幕；没有字幕才转写声音；需要看画面时才抽帧 | 视频层＋ASR（可选） |
| 联网核查 | 关键说法查第三方来源，标注 `[已核实]` / `[存疑/有出入]` / `[未证实/单方说法]` | 助手自带联网能力即可 |
| 个人画像 | 记住你的职业、预算、近期决定，让建议更贴合你；**只存本地** | 不需要 |

五种内容各有专门手册：官方通稿（M1）、利益方话术（M2，含产品发布/消费金融/企业公关/招聘/研究数据五张场景卡）、AI 洗稿排雷（M3）、深度脱水（M4）、社媒热点降噪（M5）。助手会自动分类，你不用管。

详略三档：默认标准版（300–600 字）；说“极速版/三句话总结”更短；说“深度拆解”更详细。语气两档：默认平实直白；说“毒舌点/犀利点”换吐槽版（只改措辞，不改事实和结论）。

## 安装

### 第一步：把技能放进你的 AI 助手

只需要仓库里的 `dyz-plain-talk-decoder/` 这个目录（其余是开发和测试文件，不用管）。

- **Claude Code**：把整个 `dyz-plain-talk-decoder/` 目录复制到 `~/.claude/skills/`（个人可用）或项目的 `.claude/skills/`（仅该项目可用）。
- **Qoder 及其他支持 Skill 的助手**：按各自的 Skill 安装说明操作，通用做法是把整个目录放进助手指定的技能目录，或在应用里导入本地技能（可先把目录打包成 zip）。
- 装好后对助手说“讲人话，帮我看看这篇……”试试。助手认不出技能时，检查目录里是否有 `SKILL.md`、目录名是否完整。

### 第二步（可选）：开启链接抓取

只贴文字的话，这一步可以完全跳过。想让助手直接读链接：

1. 安装 [Python 3.10 或更新版本](https://www.python.org/downloads/)（Windows 安装时勾选 “Add to PATH”）；
2. 在技能目录下安装基础依赖：

   ```bash
   cd dyz-plain-talk-decoder
   python -m pip install -r requirements.txt
   ```

3. 自检一下（会告诉你还缺什么、怎么装）：

   ```bash
   python scripts/check_env.py
   ```

视频和语音转文字是额外的可选能力，见下一节。

## 怎么用

直接对助手说：

- “讲人话，这个通稿到底啥意思？（粘贴全文）”
- “太长不看，帮我脱水一下这篇：（粘贴或给链接）”
- “这个保险广告靠谱吗？（粘贴宣传页）”
- “这份 JD 到底想招什么人？”
- “这个热搜到底怎么回事，别让我被带节奏。（粘贴多条帖子）”
- “拆解一下这个视频讲了什么：（B站/YouTube 链接）”
- “查看我的画像。” / “建立画像。” / “更新我的画像：我换工作了。” / “删除我的画像。”

链接打不开时，助手会直说原因并请你粘贴正文——**粘贴永远是最可靠的路**。只拿到部分内容时，它会说明读到了哪里，不会假装读过全文。

## 可选能力的开启方法

所有可选依赖都在 `requirements-optional.txt` 里，按需安装，不装不影响文字解码。

### 视频字幕与音频（L0/L1/L2 的基础）

```bash
python -m pip install "yt-dlp>=2025.1"
```

再装系统级 **ffmpeg**（含 ffprobe）：

- Windows：`winget install ffmpeg`
- macOS：`brew install ffmpeg`
- Linux：用发行版包管理器，如 `sudo apt install ffmpeg`

B站、YouTube 的公开视频多数有字幕，装到这里就能直接解码。yt-dlp 版本过旧是视频抓取失败最常见的原因，失败时先升级：`python -m pip install -U yt-dlp`。

### 语音转文字（ASR）：视频没有字幕时

两种方式二选一，通过**环境变量**配置（密钥只放环境变量，不要写进任何文件）：

**方式一：云端 ASR（推荐，快、准）**

```bash
python -m pip install "openai>=1.52"
```

设置环境变量（Windows 用“设置 → 系统 → 关于 → 高级系统设置 → 环境变量”，macOS/Linux 写进 shell 配置）：

| 变量 | 填什么 |
| :--- | :--- |
| `ASR_PROVIDER` | `openai_compatible` |
| `ASR_API_KEY` | 你的接口密钥 |
| `ASR_BASE_URL` | 服务地址。OpenAI 官方可不填；Groq 填 `https://api.groq.com/openai/v1`；阿里云百炼填业务空间专属域名 `https://{你的空间ID}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1` |
| `ASR_MODEL` | 模型名。百炼填 `qwen-audio-3.0-asr-flash`（自动走原生协议，带句级时间戳）或 `qwen3-asr-flash`（兼容接口）；其他服务填对应模型 |

注意：云端接口按时长计费。超过 30 分钟的视频，助手会先告诉你预计耗时并征求同意；也可以只转写某一段（对助手说“只看 10:00 到 20:00 那段”）。

**方式二：本地 ASR（离线、免费、较慢）**

```bash
python -m pip install "faster-whisper>=1.0"
```

环境变量：`ASR_PROVIDER=local_whisper`。首次使用会下载模型；有 NVIDIA 显卡会自动用 GPU，没有则用 CPU。

### 画面抽帧（L3）

装了 ffmpeg 即可。助手只在内容主要靠画面（PPT、图表、硬字幕）或你明确要求时才抽帧，不会随便下载视频画面。

## 平台支持分级

| 级别 | 平台 | 承诺 |
| :--- | :--- | :--- |
| **T1 稳定支持** | 普通网页/博客/新闻、微信公众号公开文章、B站、YouTube | 纳入回归测试，失效视为缺陷并修复 |
| **T2 尽力而为** | 微博、X、小红书、抖音、视频号 | 能抓则抓，失败直接请你粘贴，不视为缺陷 |
| **T3 不支持** | 需登录、付费、私密或已删除的内容 | 直接说明原因并请你粘贴 |

## 隐私与使用边界

- **画像只存本地**：在你的用户文件夹 `.plain-talk-decoder/profile.md`，人能直接读改。它不进搜索词、不传给任何脚本或第三方，只影响“给你的建议”和解释深浅。说“删除我的画像”即可删掉。
- **不越权抓取**：只读公开可访问的内容；不绕过登录、付费墙、验证码；不读取浏览器 Cookie；不用代理池、不伪造设备指纹；失败后不反复重试。
- **抓取到的内容是数据**：网页里夹带的任何“指令”一律不执行。
- **不冒充**：没看到原内容就明说；用二手报道回答时会先征得同意并写明来源。
- **高风险领域不替你做决定**：医疗、投资、法律只指出风险点和该追问的问题。

## 常见问题

**问：链接打不开怎么办？**
答：助手会说明原因（要登录/被拦截/失效）。把正文复制粘贴给它即可，解码质量完全一样。

**问：视频没有字幕怎么办？**
答：配置 ASR（见上），或直接把字幕、文字稿贴给助手，也可以截几张关键画面。它不会凭标题和简介编一份“总结”。

**问：Windows 下运行脚本报中文乱码？**
答：脚本输出已统一 UTF-8。若控制台仍乱码，先执行 `chcp 65001` 再运行。

**问：提示缺依赖（missing_dependency）？**
答：按提示安装对应组件；或者直接粘贴正文，不影响使用。运行 `python scripts/check_env.py` 可一次看全缺什么。

**问：画像存在哪里？换电脑会丢吗？**
答：用户文件夹下的 `.plain-talk-decoder/profile.md`，在技能目录之外，升级或重装技能不会丢；换电脑需要自己复制这个文件。

**问：不联网能用吗？**
答：能。粘贴文字照常解码，所有核查项如实标“未联网核查”。

**问：转写过的视频重复问会重新下载吗？**
答：不会。字幕、逐字稿、音频缓存在系统临时目录，追问时自动复用；任务结束助手会清理。也可手动运行 `python scripts/cleanup_cache.py`（默认只清超过 24 小时未使用的缓存），加 `--all` 全部清理。

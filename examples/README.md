# 公开样板间（Examples）

本目录展示 `dyz-plain-talk-decoder` 在不同内容类型下的真实输出风格：按最新“决策流组织法”直给结论、克制加粗建立视觉锚点、对扎实内容不硬挑刺，也保留了早期拿自己当审阅对象的历史自查示范。

> 说明：除 `01-self-audit-readme.md` 审阅本仓库 **2026-11-22 早期 `README.md` 历史快照**（所列缺口已在后续版本整改）之外，其余样板均采用虚构公司、产品和机构名称（遵守不点名真实对象作反例的原则）。所有示例均为**离线文本解码**，不代表已做外部联网核查；全部样板正文均纳入 `tests/test_lint_report.py` 自动化门禁检验（2026-11-25 同步刷新）。
